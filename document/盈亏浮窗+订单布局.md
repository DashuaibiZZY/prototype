# 一、已实现盈亏拆解浮窗

## 1.1 适用范围

|场景|触发位置|交互|
|---|---|---|
|当前持仓|「盈亏 (ROE%)」列：未实现盈亏 + ROE% 虚线区域|鼠标悬停，浮窗向下弹出|
|历史持仓|「已平仓盈亏」列：数值虚线区域|鼠标悬停，浮窗向下弹出|

当前持仓单元格**仅展示未实现盈亏与 ROE%**，不在单元格内单独展示已实现盈亏金额；已实现盈亏仅通过浮窗查看。

## 1.2 浮窗结构

浮窗分为**标题区**与**明细区**，中间用分隔线区分。

```
┌─────────────────────────────┐
│ 已实现盈亏        -45.20 USDT │  ← 标题区（小标题 + 合计）
├─────────────────────────────┤
│ 平仓盈亏          -38.10 USDT │
│ 资金费用           +2.15 USDT │
│ 交易手续费         -9.25 USDT │
└─────────────────────────────┘
```

|区域|字段|说明|
|---|---|---|
|标题区|已实现盈亏|左侧为小标题（加粗）；右侧为**合计值**，等于下方三项之和|
|明细区|平仓盈亏|已平仓部分产生的盈亏|
|明细区|资金费用|持仓期间资金费用累计（正为收入、负为支出）|
|明细区|交易手续费|相关成交手续费累计（一般为负）|

## 1.3 数值定义与计算口径

### 1.3.1 合计公式

**已实现盈亏（合计）** = 平仓盈亏 + 资金费用 + 交易手续费

### 1.3.2 不计入项

- **未实现盈亏不计入**：当前仍持仓部分的浮动盈亏不参与本浮窗任何字段的计算与展示。

### 1.3.3 统计范围

统计对象为**单笔持仓**在其生命周期内产生的全部已实现项。

**当前持仓（持仓中）：** 自开仓起至当前时刻的累计值。

**历史持仓（已关闭）：** 自开仓起至仓位完全关闭的累计值。

三项明细口径如下：

|明细项|包含内容|
|---|---|
|平仓盈亏|该持仓已成交平仓（含部分平仓、加仓后再平仓）产生的已实现盈亏累计|
|资金费用|该持仓在持仓期间各资金费率结算周期产生的费用累计|
|交易手续费|与该持仓相关的**全部**成交手续费，须包含：<br>① 最初开仓成交的手续费；<br>② 持仓过程中每一次开仓、平仓（含部分平仓）成交的手续费；<br>③ 若已全部平仓，最后一笔完全平仓成交的手续费|

若持仓经历多次开平仓，三项均为**累计值**，而非单笔成交值。

### 1.3.4 与列表展示的关系

- **当前持仓**：列表「盈亏 (ROE%)」列只显示未实现盈亏 + ROE%；浮窗合计值不重复展示在单元格内。

- **历史持仓**：「已平仓盈亏」列主数值须与浮窗标题区「已实现盈亏」合计值一致；明细三项之和等于该合计值。

## 1.4 展示与交互规则

|规则|说明|
|---|---|
|金额格式|USDT，保留两位小数；正数前缀 `+`，负数前缀 `-`|
|颜色|盈利（≥ 0）绿色；亏损（\< 0）红色|
|弹出方向|浮窗在触发元素**下方**弹出，避免被表格 sticky 表头遮挡|
|层级|`z-index` 高于表头；表格单元格 `overflow: visible`|
|触发方式|仅悬停，无需点击；鼠标移出后浮窗隐藏|
|最小宽度|约 188px；标签左对齐，数值右对齐|

# 二、订单簿底部布局切换

## 2.1 位置与布局

订单簿视图底部工具栏为固定一行，**左右分栏**：

|位置|组件|
|---|---|
|左侧|盘口布局切换（三个图标按钮）|
|右侧|精度选择下拉（见《合约交易页》4.3.5）|

Web 端订单簿底部**不再提供**计价资产（USDT / 交易币种）切换下拉；数量与累计列单位仍随交易终端等单位设置联动。

## 2.2 布局模式

提供三种互斥模式，对标主流交易所（如 OKX）订单簿视图切换：

|模式|图标示意|卖单区|买单区|中间价横条|默认|
|---|---|---|---|---|---|
|买卖各半|上红下绿两块|上半区 50% 高度|下半区 50% 高度|显示|是|
|仅买单|整块绿色|隐藏|占满可用高度|隐藏|否|
|仅卖单|整块红色|占满可用高度|隐藏|隐藏|否|

### 2.2.1 买卖各半（默认）

- 卖单区在上、买单区在下，各占订单簿挂单区域约一半高度。

- 中间保留最新成交价与标记价格横条。

- 卖单价格从高到低向中间价靠拢；买单价格从高到低向下延伸。

### 2.2.2 仅买单

- 隐藏卖单区与中间价横条。

- 买单区占满订单簿挂单可用高度。

- 挂单行数相对「买卖各半」模式增加，行间距可 `justify-between` 分布，使盘口在视觉上铺满信息框。

### 2.2.3 仅卖单

- 隐藏买单区与中间价横条。

- 卖单区占满订单簿挂单可用高度。

- 行数与铺满规则同「仅买单」。

## 2.3 交互规则

|规则|说明|
|---|---|
|默认模式|进入页面时为「买卖各半」|
|切换反馈|点击布局按钮后立即重渲染订单簿；当前选中按钮高亮（深色 + 浅灰底）|
|状态保持|切换「最新成交」Tab 后回到订单簿，保留上次所选布局模式|
|精度联动|切换布局不影响精度档位；改精度后各布局模式均按新精度聚合|
|新币未开盘|布局按钮仍展示；挂单区为空状态「暫無掛單數據」（见《合约交易页》4.5）|
|数据更新|布局模式不变时，挂单数据仍实时刷新|

## 2.4 与精度的关系

- 精度下拉位于工具栏**右侧**（自原左侧移至右侧）。

- 精度档位规则不变：4 档（基础精度 × 1 / 10 / 100 / 1000），选择后按精度聚合价格并重绘。

- 布局切换与精度切换相互独立，可任意组合使用。
