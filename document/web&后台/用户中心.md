# 用户中心（后台）

## 0. 文档概述

| 端 | 原型 |
|---|---|
| 用户列表 | [用户中心.html](https://dashuaibizzy.github.io/prototype/perp_dex/admin/用户中心.html) |
| 用户详情 | [用户中心详情.html](https://dashuaibizzy.github.io/prototype/perp_dex/admin/用户中心详情.html) |

权限：`user.center`（系统模块），读 = 查询用户与交易数据；写 = 配置用户类型、冻结项。详见《[后台权限与角色管理](后台权限与角色管理.md)》。

与用户端 **风控冻结** 模块关系：列表/详情中的「冻结」配置项与《[用户风控冻结](用户风控冻结.md)》中单项说明一致；用户中心额外支持 **登录冻结** 与 **用户类型（做市商）** 配置。

## 一、用户列表

### 1.1 查询条件

| 条件 | 说明 |
|---|---|
| UID | 精确或前缀匹配 |
| 邮箱 / 钱包地址 | 模糊匹配 |
| 用户类型 | 全部 / 普通用户 / 做市商 |
| 用户状态 | 全部 / 正常 / 部分冻结 / 冻结 |

### 1.2 列表字段

| 字段 | 说明 |
|---|---|
| UID | 主键，支持复制完整 UID |
| 邮箱 / 钱包地址 | 邮箱优先展示；钱包缩写 + 复制 |
| 用户类型 | 普通用户、做市商 |
| 最新登录时间 | 最近一次成功登录时间 |
| 过去 14 天交易量 | USDT 口径，与 VIP/费率统计一致 |
| VIP 等级 | 当前等级展示 |
| 用户状态 | 正常、部分冻结、冻结（由冻结项聚合） |

### 1.3 操作

| 操作 | 说明 |
|---|---|
| 详情 | 跳转用户详情子页 |
| 类型 | 弹窗：普通用户 / 做市商 |
| 冻结 | 右侧抽屉：冻结与交易限制（见 §三） |

列表分页：每页 10 条，规则同 Admin 通用列表交互。

## 二、用户详情

### 2.1 基础信息

| 字段 | 说明 |
|---|---|
| UID、邮箱/钱包、用户类型 | 与列表一致 |
| 最新登录时间、登录 IP | 最近一次登录 |
| 登录设备 | **弹窗列表**（时间、IP、设备/浏览器、端）；接口分页 |
| 总资产价值、资金账户余额、交易账户余额 | 合约+资金账户汇总 |
| 账户保证金比例、未实现盈亏、维持保证金 | 交易账户风险指标 |
| 过去 14 天交易量、VIP 等级 | 与列表一致 |
| 费率 (Taker / Maker)、费率有效期天数 | 含运营自定义费率剩余天数 |
| 用户状态 | 正常 / 部分冻结 / 冻结 |
| 用户冻结行为 | 提现、划转、下单、仅平仓、API 下单、登录 — 已冻结项高亮 |

### 2.2 交易数据区（只读）

与 Web **合约交易页** 底部数据区 **字段与筛选口径一致**，交互改为后台样式（筛选条 + 表格 + 查询/重置），**不提供 mock 数据行**；接口未接入时展示空状态文案。

**禁止**：当前持仓、当前委托中的 **平仓、撤单** 及任何代客交易操作。

主 Tab：

| Tab | 子 Tab / 说明 |
|---|---|
| 当前持仓 (n) | 仅当前合约、合约筛选 |
| 当前委托 (n) | 限价｜市价、止盈止损单、高级限价 |
| 历史委托 | 同上三类子 Tab + 时间快捷/自定义 |
| 历史成交 | 时间、合约、方向 |
| 历史持仓 | 时间、合约、仓位模式、状态 |
| 资金流水 | 时间、类型 |
| 资金费用 | 时间、合约 |
| 充提记录 | 见 §2.3 |

Tab 标题中 `(n)` 为接口返回条数；原型占位为 `(—)`。

### 2.3 充提记录

**子 Tab**：充值、提现、划转、授权记录、待处理。

**公共查询**：资产（下拉）、网络（下拉）、状态（下拉）、时间（最近 7 天 / 最近 30 天 / 全部）。

| 子 Tab | 表头 |
|---|---|
| 充值 / 提现 / 划转 | 类型与说明、资产与网络、金额、状态、时间 |
| 授权记录 | 创建时间、资产、数量、类型、网络、授权状态、授权时间 |
| 待处理 | 类型与说明、资产与网络、金额、状态、操作 |

后台 **待处理** 的「操作」列仅展示运营处理入口（若有）；与用户详情其他 Tab 一样，原型阶段仅表头，不预置业务按钮逻辑。

## 三、用户类型弹窗

- 单选：**普通用户** / **做市商**。
- 保存后更新列表与详情展示；做市商权限与费率策略由后续模块联动（本期原型仅类型标记）。

## 四、冻结配置（用户中心入口）

右侧抽屉，配置项与说明：

| 配置项 | 说明 |
|---|---|
| 提现冻结 | 禁止发起链上提现申请 |
| 资金划转冻结 | 禁止交易账户、资金账户之间的资金划转 |
| 下单冻结 | 禁止下单，开平仓都不允许 |
| 仅平仓模式 | 仅允许平掉已有仓位，禁止任何开仓行为 |
| API 交易冻结 | 禁止使用 API Key 进行下单，Web/App 不受影响 |
| 登录冻结 | 禁止用户登录账号 |

保存须填写 **操作备注**；写操作记入审计（与冻结操作记录打通为二期）。

用户状态聚合建议：

- **正常**：以上均未启用  
- **部分冻结**：启用任意一项且未达「冻结」定义  
- **冻结**：登录冻结且多项资金/交易限制同时启用，或产品定义的「全冻结」组合（与列表 mock 规则一致，上线以服务端为准）
