# 1. 我的活动 · 奖励记录

## 1.1 入口与命名

| 端 | 入口路径 | 文案 |
|---|---|---|
| Web | 活动中心 → **我的活动** → 页头按钮 | **奖励记录**（原「我的奖励」） |
| App | 活动中心 → **我的活动** → 导航栏右侧按钮 | **奖励记录**；点击进入独立子页面，标题同为「奖励记录」 |

- 「我的活动」仅展示用户已报名的活动列表（进行中 / 已结束）。
- 「奖励记录」为**跨业务统一发奖流水**，不仅包含平台活动 USDT 奖励，还包含费率发放、积分发放、积分加成、体验金发放等后台运营发奖记录。

## 1.2 列表字段（Web 表格 / App 卡片）

用户端「奖励记录」统一展示以下五列（App 以卡片内网格呈现）：

| 字段 | 说明 |
|---|---|
| **奖励名称** | 用户当前语言下的展示名称。平台活动取活动多语言配置；后台自定义发放取运营配置的四语言奖励名称（见各业务后台文档）。 |
| **奖励类型** | 枚举：`USDT`、`积分`、`积分加成`、`体验金`、`费率优惠`。活动类 USDT 奖励填 `USDT`。 |
| **发放金额** | 已发放或待发放的具体数值/描述。USDT 为金额；积分为 `+N Pts`；体验金为面额；费率优惠为 Taker/Maker 或 VIP 等级描述；积分加成为系数如 `1.5x`。待核算的活动奖励可展示预估金额。 |
| **发放状态** | `已发放`、`待发放`、`发放失败`。活动类奖励在活动结算前为 `待发放`；后台审批通过且系统入账后为 `已发放`。 |
| **发放时间** | 实际入账或状态变更时间，格式 `YYYY-MM-DD HH:mm:ss`（UTC+8 展示）。`待发放` 时展示 `—`。 |

### 排序与分页

- 默认按发放时间倒序；`待发放` 记录可置顶或按业务约定排序。
- Web 弹窗内分页（每页 4 条，可翻页）；App 为纵向滚动列表，支持搜索奖励名称。

## 1.3 数据来源与业务关联

奖励记录为**聚合视图**，写入来源如下：

| 来源业务 | 触发动作 | 奖励类型 | 奖励名称规则 | 发放金额 | 发放状态 | 发放时间 |
|---|---|---|---|---|---|---|
| **平台活动** | 活动结算 / 任务完成发奖 | USDT | 活动配置的多语言名称 + 奖励档位文案 | 实际到账 USDT | 结算前 `待发放`，到账后 `已发放` | 到账时间 |
| **费率发放** | 费率审批通过生效 | 费率优惠 | 关联平台活动名 **或** 自定义四语言奖励名称 | 如 `Taker 0.020% / Maker 0.008%` 或 `VIP 3` | 审批通过即时 `已发放` | 审批通过时间 |
| **积分发放**（手动） | 积分手动发放审批通过 | 积分 | 关联活动名 **或** 自定义四语言奖励名称 | `+N Pts` | 审批通过 `已发放` | 入账时间 |
| **积分加成** | 积分加成配置审批通过 | 积分加成 | 关联活动名 **或** 自定义四语言奖励名称 | 系数如 `1.5x` | 审批通过 `已发放` | 生效时间 |
| **体验金发放** | 体验金批量发放审批通过 | 体验金 | 关联平台活动名 **或** 自定义四语言奖励名称 | 体验金面额 USDT | 卡券到账 `已发放` | 到账时间 |

### 奖励名称多语言

- **关联平台活动**：奖励名称读取活动上架系统的多语言配置（与活动详情页一致），按用户当前语言展示；缺失时回退：用户语言 → 英文 → 简体中文。
- **自定义发放**（费率 / 积分 / 加成 / 体验金后台选择「自定义活动名称」）：运营须配置 **简体中文、繁体中文、英文、日本语** 四个奖励名称字段，全部必填；用户端奖励记录按语言展示对应文案。

### 与消息中心联动

- 消息中心「奖励到账」类通知的「查看奖励记录」按钮，跳转至本页「奖励记录」列表（Web 打开弹窗 / App 打开子页面）。
