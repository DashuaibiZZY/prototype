# 合伙人中心 · App 布局设计（原型阶段）

> 本文档描述 **Web 合伙人中心 → App** 的信息架构与组件布局规范。功能细则仍以 `邀请合伙人无限层返佣系统.md` §3 为准；App 专属需求文档在原型验收后补充 §4。

## 1. 设计原则

| 原则 | 说明 |
|---|---|
| **一屏一事** | 375px 宽下避免并排宽表；列表改卡片，详情改二级页 |
| **数据分层** | 首屏 KPI + 列表摘要；明细下钻到 Stack 页或 Bottom Sheet |
| **与 Web 同源** | 字段、口径、mock 数据与 Web `partner-center-user.js` 一致 |
| **手势优先** | 筛选/排序/表单用 Bottom Sheet；分享海报用全屏 Sheet |

## 2. 信息架构

```
个人中心 / 邀请返佣 / 合伙人计划
        ↓
   app/代理中心.html（Hub）
        │
        ├── Tab · 邀请链接（默认）
        ├── Tab · 团队管理
        │       └── Stack · 团队穿透（可多级）
        ├── Tab · 团队数据
        └── Tab · 佣金
                └── Stack · 佣金详情
                        └── Sheet · 交易返佣流水
```

**与 Web 侧栏对应：**

| Web 侧栏 | App 一级 Tab | App 二级 |
|---|---|---|
| 邀请链接管理 | 邀请链接 | — |
| 合伙人管理 | 团队 | Stack：团队穿透 |
| 团队数据分析 | 数据 | 维度 Tab 内嵌 |
| 佣金管理 | 佣金 | Stack：佣金详情 |

## 3. 页面壳层

```
┌─────────────────────────────┐
│ ←  标题              [操作] │  App Header（Stack 页显示返回）
├─────────────────────────────┤
│ [链接] [团队] [数据] [佣金]   │  顶部分段 Tab（Hub 页固定；Stack 页隐藏）
├─────────────────────────────┤
│  周期 / 筛选 Chip 行         │  可选工具条
├─────────────────────────────┤
│                             │
│   Scroll · 主内容区          │  KPI 网格 + 卡片列表 + 图表
│                             │
└─────────────────────────────┘
```

- **Hub 页**：保留顶部分段 Tab；内容区 `overflow-y: auto`。
- **Stack 页**：隐藏 Tab；Header 左侧返回；标题随页面变化（佣金详情 / 团队穿透）。
- **Bottom Sheet**：遮罩 + 圆角顶栏；用于筛选、创建链接、调整比例、添加下级等。
- **全屏 Sheet**：分享海报、交易流水列表（长列表可独立 Stack 页）。

## 4. Web → App 组件映射

### 4.1 KPI 与统计

| Web | App |
|---|---|
| 5 列 KPI 横排 | **2×2 + 1** 网格；第 5 项或与第 4 项合并为「团队净入金」强调卡 |
| KPI 子行 breakdown | 卡片内 **折叠区**（默认收起，点「展开明细」） |
| 佣金管理 3 张汇总卡 | 横向 **scroll-snap** 三卡或 2+1 网格 |
| 佣金详情 4 张聚合卡 | **2×2** 网格；违规扣除卡内直接展示原因（同 Web） |

### 4.2 列表与表格

| Web | App |
|---|---|
| 宽表（10+ 列） | **卡片行**：首行标题+状态；次行 2～3 个关键指标；底部操作按钮组 |
| 表头排序 | 工具栏 **排序 Chip** → Bottom Sheet 选字段+升降序 |
| 搜索框 | 顶栏搜索或列表上方 sticky 搜索 |
| 分页 10 条/页 | **加载更多** 按钮（原型）或无限滚动 |
| 行内多操作 | 主操作外露 1～2 个；其余收入 **⋯ 菜单** Sheet |

### 4.3 图表（团队数据 Tab）

| Web | App |
|---|---|
| 三列并排（趋势 / 来源 / Top10） | **纵向堆叠** 三个 section-card |
| 5 维度 Tab | 横向 scroll Tab（交易额 / 返佣 / 人数 / 交易人数 / 净入金） |
| UTC+8 提示 | 选中「团队交易人数」「团队净入金」时 Tab 下方 **纯文本提示**（同 Web PR #392） |

### 4.4 弹窗 → Sheet

| Web Modal | App |
|---|---|
| 创建/编辑邀请链接 | Bottom Sheet 表单 |
| 分享海报 | 全屏 Sheet（QR + 邀请码 + 保存/分享） |
| 添加下级合伙人 | Bottom Sheet（UID + 比例滑块 + 备注） |
| 调整返佣比例 | Bottom Sheet |
| 团队树预览 | Bottom Sheet 可折叠树 |
| 交易返佣流水 | Stack 页或全屏 Sheet 列表 |

## 5. 各 Tab 布局要点

### 5.1 邀请链接

1. **顶栏**：周期 Chip（1D/1W/1M/3M）+ 搜索
2. **摘要条**：最高比例、上级、默认邀请码（单行可横滑）
3. **列表卡片**（每条链接一张）：
   - 标题：备注名 + 状态徽章
   - 邀请码 monospace + 复制
   - 指标网格 2×3：直邀人数、下级合伙人数、总交易额、手续费、返佣、净入金
   - 操作：复制链接 | 分享 | 修改 | 启停
4. **FAB / 底栏按钮**：创建新链接（使用中 n/50）

### 5.2 团队管理

1. **身份卡**：上级 UID/钱包 + 我的比例
2. **周期 + 5 KPI**（2×2+1 网格，可展开 breakdown）
3. **子 Tab**：直属下级合伙人 | 自邀直客
4. **列表卡片**：UID/钱包、比例、级差、团队规模、操作（查看团队 / 调整）
5. **Stack · 团队穿透**：面包屑 + 只读 KPI + 下级列表（脱敏规则同 Web）

### 5.3 团队数据

1. 周期选择 + 5 KPI（含环比 delta）
2. 维度 Tab + 可选 UTC+8 提示
3. 趋势图（全宽）
4. 来源分布（简化为 stacked bar 或列表）
5. Top 10 排行榜（卡片列表，非宽表）

### 5.4 佣金

1. 三 KPI 汇总卡
2. 筛选：日期 + 状态 Chip → Sheet
3. **日结算卡片**：日期、状态、交易额、手续费、返佣（含违规虚线提示）、【佣金详情】
4. **Stack · 佣金详情**：4 聚合卡 + UID 列表卡片 + 【交易流水】
