# 持仓管理 \& 资金流水 模块

**原型（合约交易页 · 信息内容模块）**：[https://dashuaibizzy.github.io/prototype/perp_dex/合约交易.html](https://dashuaibizzy.github.io/prototype/perp_dex/合约交易.html)

**原型（投资组合页 · 充提记录）**：[https://dashuaibizzy.github.io/prototype/perp_dex/投资组合.html](https://dashuaibizzy.github.io/prototype/perp_dex/投资组合.html)

## 模块概述

本模块位于交易页面下半区，集中展示用户交易数据与资产变动记录。

左侧为主数据区，通过顶部标签切换视图；右侧为账户权益及保证金概览面板（固定展示，不受标签切换影响）。

- 适用页面：合约交易页、投资组合页（投资组合页额外增加「充提记录」标签，其余一致）。

**计价与数量展示约定**

- 页面内金额类字段（保证金、盈亏、手续费等）统一以 **USDC** 计价展示。
- **数量类字段的展示单位** 与合约交易页 **交易终端「下单数量」的全局单位选择** 联动（USDC 名义价值 / BTC 等交易币种币数），详见下文 **2.4 全局数量单位联动**。

## 整体布局与交互框架

### 2\.1 主标签栏

页面截图：[**主标签栏 · 当前持仓**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-tab-pos.png)

从左至右依次为：

1. 当前持仓（显示 “当前持仓 \(N\)”，N 为持仓数量）

2. 当前委托（显示 “当前委托 \(N\)”，N 为所有委托单总数）

3. 历史委托

4. 历史成交

5. 历史持仓

6. 资金流水

7. 资金费用

8. 充提记录（仅投资组合页显示）

交互规则：

- 点击标签，标签高亮（黑色加粗 \+ 底部 2px 黑色下划线），其余变灰。

- 表格和筛选栏内容动态切换，无需整页刷新。

- 「隐藏其他合约」复选框：勾选后，仅显示当前交易对数据；取消勾选则显示全部合约。该开关影响当前持仓、当前委托的数据。

### 2.4 全局数量单位联动

交易终端「下单数量」处选择的单位（**USDC / BTC**）为本模块数量展示的 **全局开关**，不在持仓模块内单独切换。

|概念|说明|
|---|---|
|USDC|计价币种；数量列展示名义价值（如 `31,233.23 USDC`）|
|BTC|当前交易对的 **交易币种（基础资产）**；数量列展示币数（如 `0.500 BTC`）|

**联动范围**

- **当前持仓**：「数量」列主展示随全局单位切换。
- **当前委托**：「数量」「成交数量」等字段的展示单位与数值格式。
- **历史委托 / 历史成交 / 历史持仓**：列表中数量类字段的展示（筛选逻辑不变）。

**当前持仓数量列 hover 说明**

- 鼠标悬停数量区域，固定展示 tooltip 三项：**交易方向**、**持仓币数**、**持仓价值**（不受主展示单位影响）。

**与平仓操作的关系**

- 标准平仓、快捷平仓中的平仓数量输入框、持仓量、可平量等，**同样随全局数量单位联动**（见 3.1.2）。

### 2.5 当前持仓标签操作区

当主标签为「当前持仓」时，标签栏右侧额外展示：

|控件|说明|
|---|---|
|一键平仓|点击弹出确认弹窗；确认后按市价平掉全部持仓并撤销相关平仓挂单|
|隐藏其他合约|见 2.1|

**一键平仓确认文案**：提示将以市价平仓全部仓位，可能导致较大滑点；确认 / 取消。

### 2.6 子标签（仅“当前委托”与“历史委托”）

页面截图：[**当前委托 · 基础单**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-tab-order-base.png)

页面截图：[**当前委托 · 止盈止损单**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-tab-order-tpsl.png)

当主标签为“当前委托”或“历史委托”时，在主标签栏下方出现子标签行：

- 基础单：显示常规限价单、市价单等。

- 止盈止损单：显示条件委托（止盈/止损单）。

交互：

- 子标签选中态：黑色文字 \+ 底部 2px 黑色下划线；未选中态：灰色文字。

- 切换子标签时，表头、数据行同步切换；历史委托下的筛选栏也会根据子标签变化（基础单显示订单类型、方向等筛选项；止盈止损单隐藏这些筛选项）。

### 2.7 表头说明浮窗（虚线提示列）

部分列表表头字段带**虚线下划线**，表示可查看字段释义。交互统一如下：

|规则|说明|
|---|---|
|触发|鼠标悬停虚线表头文字|
|默认状态|不展示说明文案|
|浮窗方向|在表头文字**下方**弹出白色说明面板（避免被主标签栏遮挡）|
|浮窗样式|白底、浅灰边框、阴影；小号灰色正文|
|移出|鼠标移出表头触发区域后浮窗隐藏|

**适用字段（当前持仓）**

|表头|说明文案|
|---|---|
|標記價格|最新标记价格，用于计算盈亏和强平|
|盈虧平衡價|持仓达到盈亏平衡时的价格|
|預估強平價|预估强平价数据仅供参考。实际强平价会根据账户权益、维持保证金和浮动收益的变化而产生差异。|
|联合保证金率|维持保证金率可衡量合约仓位的风险情况；维持保证金率越低，仓位风险越大；当维持保证金率≤100%时，会触发强减或强平。|

**适用字段（历史持仓）**

|表头|说明文案|
|---|---|
|最大持仓量|您的持仓曾达到的最大规模 (非累积计算)|

## 各标签详细字段与数据状态说明

以下按主标签说明 **字段定义、数据状态、展示规则与交互**；各状态枚举与颜色规则以本节为准。

### 3\.1 当前持仓

页面截图：[**当前持仓列表**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-tab-pos.png)

#### 3\.1\.1 字段定义

|字段|说明|
|---|---|
|合約|交易对名称 + **仓位模式**（全仓 / 逐仓，灰色小字）+ **杠杆倍数标签**（如 `20x`，多仓绿色底、空仓红色底）|
|數量|当前持仓数量；**主展示单位与交易终端全局数量单位联动**（USDC → 持仓价值；BTC → 持仓币数）；悬停展示交易方向 / 持仓币数 / 持仓价值|
|開倉均價|该笔持仓的开仓成交均价（USDC）|
|標記價格|最新标记价格；表头带虚线提示（见 2\.7）|
|盈虧平衡價|持仓盈亏平衡价格；表头带虚线提示（见 2\.7）|
|預估強平價|预估强平价格；表头带虚线提示（见 2\.7）|
|联合保证金率|该笔持仓的维持保证金率（%）；表头带虚线提示（见 2\.7）；数值越低风险越高|
|保證金|该笔持仓占用的保证金（USDC）|
|盈虧 (ROE%)|见 3\.1\.1\.1|
|止盈/止損|已设置的止盈价 / 止损价，或 `-- / --`|
|操作|标准平仓 / 快捷平仓、数量输入、一键平仓等|

**3\.1\.1\.1 盈亏 (ROE%) 列**

本列仅展示**未实现盈亏**及**投资回报率（ROE%）**，不在单元格内单独展示已实现盈亏数值。

|展示项|格式|颜色|
|---|---|---|
|未实现盈亏|如 `+166.05 USDC`|盈利绿色，亏损红色|
|ROE%|如 `(+25.40%)`，显示在未实现盈亏同一行或紧邻下一行|与未实现盈亏同色|

- 未实现盈亏 + ROE% 区域带**虚线下划线**，表示可查看已实现盈亏拆解。

- 鼠标悬停虚线区域，在下方弹出**已实现盈亏拆解浮窗**（见 3\.1\.1\.2）。

- 盈亏列右侧保留分享图标，行为见 4\.2\.1。

**3\.1\.1\.2 已实现盈亏拆解浮窗（当前持仓）**

页面截图：[**已实现盈亏拆解浮窗**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-float-realized-pnl.png)

**触发方式：** 鼠标悬停「盈亏 (ROE%)」列中带虚线的未实现盈亏区域。

**浮窗结构：**

浮窗自上而下分为**标题区**与**明细区**，标题区与明细区之间用分隔线区分。

|区域|字段|说明|
|---|---|---|
|标题区|已实现盈亏|小标题样式（加粗）；右侧展示该持仓生命周期内的**已实现盈亏合计值**|
|明细区|平仓盈亏|该持仓已平仓部分产生的盈亏合计|
|明细区|资金费用|该持仓生命周期内累计资金费用（正为收入、负为支出）|
|明细区|交易手续费|该持仓生命周期内累计交易手续费（一般为负值）|

**数值定义与计算口径：**

- **已实现盈亏（合计）** = 平仓盈亏 + 资金费用 + 交易手续费。

- **不计入未实现盈亏**：当前仍持仓部分的浮动盈亏不在本浮窗统计范围内。

- **统计范围**：自该笔持仓开仓起至当前时刻，与该持仓关联的全部已实现项，包括：

    - **平仓盈亏**：已成交的平仓（含部分平仓、加仓后再平仓）所产生的已实现盈亏。

    - **资金费用**：该持仓在持仓期间各结算周期产生的资金费用累计值。

    - **交易手续费**：与该持仓相关的全部成交手续费，须包含：

        - 最初开仓成交的手续费；

        - 持仓过程中每一次开仓、平仓（含部分平仓）成交的手续费；

        - 若已全部平仓，须包含最后一笔完全平仓成交的手续费。

- 若持仓过程中存在多次开平仓，上述三项均为**累计值**，而非单笔成交值。

**展示规则：**

- 金额统一以 USDC 计价，保留两位小数；正数前缀 `+`，负数前缀 `-`。

- 盈利（≥ 0）绿色，亏损（\< 0）红色。

- 浮窗在触发元素**下方**弹出，避免被表格 sticky 表头遮挡；`z-index` 高于表头。

- 浮窗内字段左对齐标签、右对齐数值，最小宽度约 188px。

#### 3\.1\.2 平仓操作（标准平仓 / 快捷平仓）

**功能定位**

「标准平仓」与「快捷平仓」是 **同一套平仓能力的两套交互形态**：区别仅在于参数填写入口（弹窗 vs 行内），**最终提交的订单类型、挂单占用处理、确认弹窗、下单后列表联动完全一致**。

单笔持仓平仓最终只会落到以下 **三种订单类型** 之一（见 3.1.2.4）：

|订单类型|说明|
|---|---|
|限价平仓|按用户指定 **价格 + 数量** 提交限价平仓单|
|市价平仓|按用户指定 **数量** 提交市价平仓单（无委托价格）|
|市价全平|不填写数量；系统 **先撤占用挂单，再对剩余全部持仓提交市价平仓**|

---

**3.1.2.1 模式切换与操作区**

表头文案为「标准平仓」或「快捷平仓」，右侧带 **切换图标**（双向箭头），点击在两种模式间循环切换。

|模式|表头|操作区|
|---|---|---|
|标准平仓（默认）|标准平仓 + 切换图标|左对齐按钮：「平仓」「市价全平」|
|快捷平仓|快捷平仓 + 切换图标|行内：价格选择 + 数量选择（滑块）+「平仓」「市价全平」；下方预计收益|

页面截图：[**快捷平仓行**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-quick-close.png)

**3.1.2.2 标准平仓 · 交互与字段**

**（1）「平仓」按钮 → 标准平仓弹窗**

页面截图：[**标准平仓弹窗**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-modal-position-close.png)

|字段|说明|
|---|---|
|合约信息|交易对 + 方向 + 仓位模式 + 杠杆（如 `BTCUSDC 永续 多 全仓 10x`）|
|标记价格|当前标记价（USDC），只读参考|
|开仓均价|该笔持仓开仓均价（USDC），只读参考|
|平仓价格|默认填入当前标记价；可编辑。右侧「市价」按钮可在 **限价 / 市价** 间切换：切为市价后输入框置灰显示「市价」|
|平仓数量|支持手动输入；数量按全局数量单位（USDC 名义 / 交易币种币数）换算。**滑块** 0% / 25% / 50% / 75% / 100% 按可平量比例选取；**数量输入框展示换算后的具体数值，不带单位后缀**（不展示百分比）。滑块面板下方展示 **持仓量** 提示（含单位，如 `持仓量 10,032.23 USDC`）|
|持仓量|该笔持仓当前总量；单位与全局数量单位联动|
|可平量|当前可立即平仓数量；单位与全局数量单位联动|
|预计收益|按当前价格与数量估算的平仓盈亏（USDC）；随价格/数量变化刷新|

**交互**

- 点击「市价」：价格区切换为市价模式；再次点击恢复限价并可编辑价格。
- 滑块与数量输入框双向联动；精度按合约最小交易单位向下取整。
- 点击弹窗底部「平仓」：关闭弹窗，进入 **平仓二次确认**（见 3.1.2.6），确认后按价格模式提交 **限价平仓** 或 **市价平仓**。
- 点击「取消」或右上角关闭：不提交订单。

**（2）「市价全平」按钮**

- 弹出 **市价全平确认弹窗**（见 3.1.2.6），确认后提交 **市价全平** 订单类型。
- 若用户在偏好设置中关闭「市价全平二次确认」，或在本弹窗勾选「下次不再提示」，则跳过后续确认直接提交。

**3.1.2.3 快捷平仓 · 交互与字段**

行内就地填写参数，无需打开标准平仓弹窗。

|控件|说明|
|---|---|
|价格框|点击展开下拉：**市价** / **最新价**。选「市价」→ 提交市价平仓；选「最新价」→ 以当前最新成交价作为限价，提交 **限价平仓**|

**3.1.2.4 三种平仓订单类型（业务逻辑）**

以下数量逻辑以 **交易币种持仓数量** 表述（文档金额展示仍以 USDC 名义；底层换算由系统按标记价/最新价处理）。

**（1）限价平仓**

- 用户指定 **委托价格** 与 **委托数量**。
- 提交 **限价平仓单**（方向：持多 → 卖出平多；持空 → 买入平空）。
- 支持任意合法数量，包括 **100% 可平量**（即当前未平仓的全部持仓对应数量）。
- 若存在挂单占用导致 **本次数量无法直接挂出**，按 3.1.2.5 自动撤单后再下单。

**（2）市价平仓**

- 用户仅指定 **委托数量**（无价格输入；快捷模式选「市价」、标准模式切为市价均走此类型）。
- 提交 **市价平仓单**，按市场深度即时撮合。
- 数量规则、挂单占用与自动撤单逻辑与限价平仓 **完全相同**（见 3.1.2.5）。
- 支持 100% 可平量。

**（3）市价全平**

- 用户 **不填写数量**；系统对 **该笔持仓的全部未平仓数量** 执行平仓。
- 执行顺序固定为两步：
  1. **撤销** 该合约、该仓位方向上所有 **占用平仓能力的挂单**（含限价平仓单，以及占用该仓位平仓数量的止盈/止损等条件单；具体范围以交易引擎规则为准）。
  2. 对撤销后剩余的 **全部持仓** 提交 **一笔市价平仓单**（数量 = 剩余全部未平仓数量）。
- 与「市价平仓 + 100% 数量」的区别：市价全平 **必定先全量撤占用单**，且数量始终为全部剩余持仓，无需用户输入。

**3.1.2.5 挂单占用与自动撤单规则**

**概念**

|术语|说明|
|---|---|
|总持仓量|该笔持仓当前未平仓的总数量（交易币种）|
|挂单占用量|同一合约、同一持仓方向上，已挂出且 **尚未成交** 的平仓类委托所占用的数量合计（含限价平仓、市价平仓未成交部分等）|
|可平量|总持仓量 − 挂单占用量（尚未被挂单冻结、可立即用于新平仓委托的数量）|

**自动撤单触发条件（限价平仓 & 市价平仓）**

当用户提交的 **本次平仓数量** 大于当前 **可平量** 时，系统在提交新单前 **自动撤销** 部分或全部已有平仓挂单，以释放占用数量。

**示例（总持仓 1 BTC，已挂限价平仓 0.5 BTC）**

|用户新单数量|系统行为|
|---|---|
|1 BTC|可平量仅 0.5 → 先撤掉已挂 0.5 → 再提交 1 BTC 平仓单|
|0.7 BTC|可平量不足 → 先撤已挂 0.5 → 再提交 0.7 BTC 平仓单|
|0.3 BTC|可平量 0.5 足够 → **无需撤单**，直接提交 0.3 BTC 平仓单|

**撤单优先级**

- 仅撤销 **同一合约、同一持仓方向、占用平仓数量** 的挂单。
- 按 **挂单时间从早到晚** 依次撤销，直到释放的数量 **满足本次下单数量**，或相关挂单已全部撤完。
- 被系统自动撤销的订单，在历史委托中状态为「已取消」，并附带系统原因（如「因新平仓委托自动撤单」）。

**市价全平的撤单范围**

- 不比较数量大小；**一律先撤销** 该仓位上所有占用平仓能力的挂单（含限价/市价未成交部分及关联条件单，以引擎规则为准），再对 **全部剩余持仓** 下市价平仓。

**3.1.2.6 确认弹窗**

**（1）标准平仓弹窗**

见 3.1.2.2；为参数填写步骤，非最终下单确认（最终确认见下）。

**（2）平仓二次确认弹窗（限价平仓 / 市价平仓）**

在用户点击「平仓」（标准弹窗或快捷行内）且通过前端校验后弹出。

|字段|说明|
|---|---|
|标题|交易对 + 方向（如 `BTCUSDC 平多`）|
|订单类型|限价单 / 市价单|
|价格|限价平仓显示委托价（USDC）；市价平仓显示「市价」|
|数量|本次平仓数量（USDC 名义展示）|
|标记价格|当前标记价（参考）|
|预估强平价|可选展示（与开仓确认一致）|

**交互**

- 「确认」：提交对应限价或市价平仓单；关闭弹窗；Toast「下单成功」或失败原因。
- 「取消」：不提交。
- 若用户在偏好设置中开启「限价单/市价单二次确认」，且未勾选「不再提示」，则每次均弹出；平仓场景复用同一套确认偏好（平仓限价视为限价单，平仓市价视为市价单）。

**（3）市价全平确认弹窗（单仓位）**

|元素|说明|
|---|---|
|标题|市价全平|
|正文|确认对该合约、方向、杠杆仓位执行市价全平（动态填充合约标签）|

|按钮|取消 / 确认|

确认后执行 3.1.2.4（3）市价全平流程。

**（4）一键平仓确认（标签栏）**

作用于 **全部持仓**，非单行「市价全平」。确认后对各持仓分别执行市价全平逻辑（先撤占用单再全平），并撤销相关平仓挂单。文案见 2.5。

**3.1.2.7 下单后联动**

**当前委托 · 基础单**

|场景|联动|
|---|---|
|限价/市价平仓提交成功|新增一行：类型「限价单」或「市价单」，方向「卖出/平多」或「买入/平空」，价格/数量与提交一致；未成交部分显示在列表中|
|发生自动撤单|被撤订单从当前委托移除；历史委托新增「已取消」记录（含系统撤单原因）|
|部分成交|当前委托行更新成交数量、成交均价；持仓数量减少|
|完全成交|订单从当前委托移除；进入历史委托「全部成交」|

**当前委托 · 止盈止损单**

- 若市价全平或自动撤单波及条件单，相关止盈/止损单从当前委托移除，历史委托中状态为「已取消」并注明原因。

**当前持仓**

|场景|联动|
|---|---|
|部分平仓成交|「数量」列减少；未实现盈亏、联合保证金率等实时刷新；可平量更新|
|全部平仓成交|该持仓行移除（或数量归零）；标签栏「当前持仓 (N)」计数减 1|
|市价全平|持仓一次性清零；占用该仓位的挂单全部清除|

**历史委托 / 历史成交**

- 成交部分进入 **历史成交**（时间、价格、数量、手续费、已实现盈亏等）。
- 订单终态进入 **历史委托**（完全成交 / 部分成交 / 已取消）。

**资金与账户**

- 保证金占用、未实现盈亏、账户权益随成交实时更新。
- 手续费在成交时扣除；已实现盈亏计入资金流水（类型「已实现盈亏」）。

**反馈**

- 成功：Toast「下单成功」或「市价全平委托已提交」等。
- 失败：Toast 展示后端原因（如数量低于最小交易单位、无可平仓位等）。

#### 3\.5\.2 已实现盈亏拆解浮窗（历史持仓）

页面截图：[**历史持仓 · 已实现盈亏拆解浮窗**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/持仓流水/pos-flow-float-realized-pnl.png)

**触发方式：** 鼠标悬停「已平仓盈亏」列中带虚线的数值区域。

**浮窗结构：** 与当前持仓一致（见 3\.1\.1\.2），分为标题区「已实现盈亏（合计）」与明细区三项（平仓盈亏、资金费用、交易手续费）。

**数值定义与计算口径：**

- **已实现盈亏（合计）** = 平仓盈亏 + 资金费用 + 交易手续费。

- **统计范围**：该笔历史持仓从首次开仓至仓位完全关闭（或列表记录结束）的整个生命周期，包括：

    - **平仓盈亏**：该持仓全部平仓成交产生的已实现盈亏合计。

    - **资金费用**：持仓期间各结算周期资金费用累计值。

    - **交易手续费**：与该持仓相关的全部成交手续费，须包含最初开仓手续费、中间过程每一次开平仓手续费，以及最后一笔完全平仓手续费。

- 历史持仓的合计值应与「已平仓盈亏」列主展示数值一致；浮窗明细三项之和等于合计值。

**展示规则：** 与 3\.1\.1\.2 相同（USDC、两位小数、正负色、浮窗向下弹出）。

#### 3\.5\.3 数据状态

状态枚举：

- 已全部平仓：持仓数量 == 已平仓数量。

- 部分平仓：持仓数量 \> 已平仓数量，但仓位已整体关闭（手动关闭剩余部分后显示此状态）。

分享按钮：点击弹出分享海报弹窗，动态展示该仓位的盈亏数据。

触发方式

点击任意筛选栏中日历图标按钮，在按钮下方弹出日期范围选择面板。

面板布局

- 宽度约 520px，白色背景，阴影边框，包含：

    - 顶部标题栏：标题文字“選擇日期範圍”，右侧关闭按钮（✕）。

    - 主体区域：左右并排两个月份日历（默认显示当前月与下个月）。

    - 每个日历内：

        - 顶部月份切换按钮（左右箭头 `<` `>`），可独立切换月份。

        - 星期头：日一二三四五六。

        - 日期网格：6行×7列，显示该月所有日期（含前后月灰色日期）。

    - 底部操作栏：

        - 左侧显示已选范围文本，格式 `YYYY-MM-DD 至 YYYY-MM-DD`。

        - 右侧“确定”按钮（黑色）。

交互规则

1. 日期选择

    - 点击日历中的某个日期，作为起始日期。

    - 再次点击另一个日期，作为结束日期。

    - 若先点击的日期晚于后点击的日期，自动交换起止顺序。

    - 选中范围高亮显示：

        - 起始日期和结束日期使用深色背景（如蓝色）加白色文字。

        - 范围中间日期使用浅色背景（如淡蓝色）。

    - 用户可反复点击修改范围，每次点击重新设定起止点。

2. 月份切换

    - 左右箭头分别切换到上月/下月，且左右日历可独立切换。

    - 当起止日期不在同一月份时，左右日历会自动调整显示对应月份，方便用户查看已选范围。

3. 快捷时间联动

    - 当用户通过快捷按钮（近1日、近7日等）更改时间时，日历面板中的选中日期和高亮范围自动更新，反之亦然（日历选择后不会自动更新快捷按钮状态，但日期筛选栏会显示正确范围）。

4. 确定与关闭

    - 点击“确定”按钮：

        - 面板关闭，外部筛选栏显示的日期文本更新为 `起始日期 - 结束日期`（如 `2026-06-03 - 2026-06-15`）。

        - 自动触发数据查询。

    - 点击右上角关闭按钮（✕）或点击面板外部区域：

        - 面板关闭，不保存未确认的日期修改。

        - 筛选栏日期文本恢复为打开面板前的值。

    - 在面板内切换月份和点击日期不会关闭面板。

5. 键盘与辅助

    - 暂不支持键盘操作，所有交互通过鼠标点击完成。

    - 日期格子 hover 时显示浅灰色背景，表示可点击。

边缘情况处理

- 若用户仅点击了一个日期（未选择范围），点击确定时：

    - 系统将该日期同时作为起始和结束日期，范围变为单日。

- 若起始日期为未来日期、结束日期为过去日期，系统自动纠正顺序，不提示错误。

- 日历中显示的前后月份日期（灰色文字）不可选。

- 面板的 `z-index` 设为 50，确保不被表格或其他内容遮挡。

**入口**：当前持仓行「止盈/止损」列「设置」按钮。

#### 4\.3\.2 委托关联止盈止损设置（基础单）

**入口**：当前委托 · 基础单列表「止盈/止损」列「设置」按钮（仅基础单；止盈止损单子标签无此列）。

**弹窗标题**：`止盈止損設置`

**上部挂单摘要**

|区域|内容|
|---|---|
|合约与方向|交易对 + 方向标签（如 `BNBUSDC` `開多`）|
|數量 (USDC / BNB)|主单数量，双单位展示（名义 USDC + 基础资产币数）|
|委託價格|主单委托价格（USDC）|

**温馨提示**（蓝色左侧竖线提示框）：主訂單成交後，系統將自動按以下觸發價格掛出相應的止盈止損單。

**止盈区**

|元素|说明|
|---|---|
|类型标签|随方向变化，如 `市價止盈平多`|
|触发价输入|`止盈觸發價格`；右侧触发类型下拉：標記價格 / 最新價格|
|预估收益行|输入触发价且数量有效时，在输入框**下方**展示动态预估收益（如 `做多止盈预估收益 +X.XX USDC`）；盈利绿色、亏损红色；随触发价、主单数量、委托价变化实时刷新|

**止损区**

|元素|说明|
|---|---|
|类型标签|如 `市價止損平多`|
|触发价输入|`止損觸發價格`；触发类型下拉同止盈区|
|预估收益行|规则同止盈区（如 `做多止损预估收益 -X.XX USDC`）|

**展示规则补充**

- 不再在触发价输入旁展示「未生效」等静态状态标签；未触发状态以列表「生效时间」列为 `--` 体现。
- 底部主按钮：`設置`；点击后保存跟随止盈止损配置并关闭弹窗。

**业务逻辑**（与跟随止盈止损需求一致）

- 主单部分成交或完全成交后，系统按预设触发价自动挂出相应止盈止损单。
- 预估收益按主单委托价与触发价、数量估算该腿触发后的盈亏，仅供用户参考。

完整规则参见《[跟随止盈止损功能](合约交易页.md)》5\.7。
