# 导航栏

**原型**

- 导航栏整体（合约交易页）：[合约交易.html](https://dashuaibizzy.github.io/prototype/perp_dex/合约交易.html)

### 概述

页面截图：[**Web · 顶部导航栏整体**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/导航栏/web-nav-bar-full.png)

除「设置」图标外，所有元素在所有页面保持一致。  
充值、提现、划转的表单与确认流程详见《[登录、划转与充提](https://ksgf73ukjokp.sg.larksuite.com/wiki/Rf9bwrHoNiU3ykkoa45lUacYgdb)》；消息中心详见站内消息文档。

#### 3\.5 用户钱包入口

全局位于导航栏最右侧。未登录展示「连接钱包」；已登录展示当前身份摘要（钱包地址或邮箱）及下拉浮窗。交互原型以《投资组合》页导航栏为准。

##### 3\.5.1 未登录态

| 元素 | 说明 |
|---|---|
| 主按钮 | 文案「连接钱包」 |
| 点击 | 打开「登录 / 注册」居中 Modal（见 §3.5.5） |

##### 3\.5.2 已登录 · 顶栏入口

| 登录方式 | 顶栏按钮展示 | 下拉触发 |
|---|---|---|
| 钱包登录 | 简化钱包地址（如 `0xd593...2Dd2`） | 悬停展开用户信息浮窗 |
| 邮箱登录 | 登录邮箱 | 悬停展开用户信息浮窗 |

入口右侧带绿色在线状态点与下拉箭头；悬停箭头可旋转示意展开。

##### 3\.5.3 用户信息下拉浮窗

**布局**（自上而下）：

1. **UID 行**：左侧 FX 头像块 + `UID: {uid}`；**右侧复制图标**，复制完整 UID。
2. **账户信息区**（见 §3.5.4 登录态差异）。
3. **总资产价值**：灰色卡片，展示估值（如 `$12,450.50`）。
4. **快捷操作**：三列按钮——充值、提现、划转（表单与校验见充提文档）。
5. **导出邮箱钱包**（仅邮箱登录，见 §3.5.8）。
6. **退出登录**：整行可点，红色文案 + 退出图标。

**浮窗交互**

- 触发：鼠标悬停顶栏钱包/邮箱入口；移出入口与浮窗区域后收起（可与全站下拉一致，带短延迟防误触）。
- 复制：UID、邮箱、钱包地址行均在**最右侧**提供复制图标；点击复制**完整值**（非缩略展示），Toast「已复制」。

##### 3\.5.4 登录方式与账户信息展示（对齐 App）

钱包登录与邮箱登录**互斥**，登录后**不支持**交叉绑定（钱包登录后不可再绑邮箱；邮箱登录后不可再绑外部钱包）。

| 能力 | 钱包登录 | 邮箱登录 |
|---|---|---|
| 下拉 · 邮箱行 | **不展示** | 展示登录邮箱 + 复制 |
| 下拉 · 钱包行 | 展示已连接钱包地址 + 复制 | 展示 Privy 为邮箱账户**自动生成**的钱包地址 + 复制（仅展示地址，无额外说明文案） |
| 下拉 · 身份验证器行 | **不展示** | 展示状态与入口（见 §3.5.7） |
| 下拉 · 导出邮箱钱包 | **不展示** | 展示入口（见 §3.5.8） |
| 顶栏标签 | 钱包地址 | 邮箱 |

邮箱登录用户的链上地址由 Privy 托管生成，用于充提等链上操作；与「连接 MetaMask / OKX 等外部钱包登录」不是同一概念。

##### 3\.5.5 登录 / 注册 Modal

**触发**：未登录时点击「连接钱包」。

**顶栏**：标题「登录 / 注册」；右侧关闭 ✕。

**结构**（自上而下）：

1. **邮箱登录区**
    - 邮箱输入框
    - 第一步：「发送验证码」
    - 第二步（发送后）：6 位验证码输入、「登录」、「重新发送验证码」
2. **分隔**：虚线 + `OR`
3. **钱包登录区**：钱包列表行（MetaMask、OKX Wallet 等），点击即连接并完成登录。

**规则**

- 邮箱与钱包为两种独立登录路径；**不提供**登录后的「绑定邮箱」「绑定外部钱包」入口或弹窗模式。
- 邮箱验证码登录成功 → 邮箱登录态，并带有 Privy 钱包地址。
- 钱包连接成功 → 钱包登录态，仅关联该外部钱包地址。

##### 3\.5.6 身份验证器 App（Web 居中 Modal）

**适用范围**：仅**邮箱登录**用户；钱包登录用户不展示下拉内身份验证器行。

**技术标准**：TOTP（RFC 6238）；6 位数字动态码，周期 30 秒；兼容 Google Authenticator、Microsoft Authenticator 等。

**下拉入口**

| 绑定状态 | 展示 | 操作 |
|---|---|---|
| 未设置 | 状态「未设置」（琥珀色） | 文字链「绑定」→ 打开 Modal |
| 已绑定 | 状态「已绑定」（绿色） | 文字链「管理」→ 打开已绑定管理 Modal |

**交互形态**：Web **居中 Modal**（与充提弹窗一致）：顶栏标题 + 左侧 **← 返回**（子步骤）+ 右侧 **✕ 关闭**；非 App 全页路由。

**状态机**（与 App 端能力对齐）：

```Plain Text
未绑定
  → [立即绑定] → 扫码/密钥 → 验证码确认 → 已绑定

已绑定
  → [修改验证器] → 验证旧码 → 扫码/密钥 → 验证码确认 → 已绑定（新密钥）
  → [移除验证器] → 风险提示 + 验证动态码 → 未绑定
```

**① 未绑定 · 引导**

| 元素 | 说明 |
|---|---|
| 标题 | 身份验证器 App |
| 主标题 | 绑定身份验证器 App |
| 说明 | 绑定后可使用动态验证码保护账户安全 |
| 辅助 | 支持 Google Authenticator、Microsoft Authenticator 等标准 TOTP 应用 |
| 主按钮 | 立即绑定 → 扫码/密钥步骤 |

**② 绑定 · 扫码/密钥**

| 元素 | 说明 |
|---|---|
| 顶栏 | ← 返回引导页；标题「绑定验证器」 |
| 说明 | 使用身份验证器 App 扫描二维码，或手动输入密钥 |
| 二维码 | 服务端下发的 TOTP QR |
| 手动密钥 | 分段/单行展示；提供「复制密钥」 |
| 主按钮 | 下一步 → 验证码确认 |

**③ 绑定 · 验证码确认**

| 元素 | 说明 |
|---|---|
| 顶栏 | ← 返回扫码页；标题「验证绑定」 |
| 输入 | 6 位动态码（单框或 6 格，以设计稿为准） |
| 主按钮 | 确认绑定 → 已绑定管理态 |

**④ 已绑定 · 管理**

| 元素 | 说明 |
|---|---|
| 状态卡 | 已绑定身份验证器、已启用动态验证码保护、安全等级：高 |
| 修改验证器 | 进入验证旧码步骤；辅助灰字：更换手机或验证器 App 时需重新绑定 |
| 移除验证器 | 进入移除确认；辅助灰字：移除后账户安全等级将降低 |

**⑤ 修改 · 验证旧码**

| 元素 | 说明 |
|---|---|
| 顶栏 | ← 返回管理页；标题「修改验证器」 |
| 说明 | 验证当前身份验证器；请输入旧验证器中的 6 位动态码 |
| 主按钮 | 下一步 → 重新走扫码/密钥 → 验证码确认（轮换 secret） |

**⑥ 移除 · 安全确认**

| 元素 | 说明 |
|---|---|
| 顶栏 | ← 返回管理页；标题「移除验证器」 |
| 风险提示块 | 安全风险提示 + 移除影响说明（红色浅底） |
| 验证 | 输入验证器动态码确认移除 |
| 按钮 | 确认移除（危险样式）、取消（返回管理页） |

移除成功后：下拉状态同步为「未设置」；设置类页面（若有）状态一致。

**异常**

| 场景 | 处理 |
|---|---|
| 验证码错误 | 行内错误提示，可重试 |
| 绑定中途关闭 Modal | 未确认绑定则 secret 不生效 |
| 多端 | 以服务端最新绑定状态为准 |

##### 3\.5.7 导出邮箱钱包（Web 居中 Modal）

**入口**：用户信息下拉浮窗 ·「导出邮箱钱包」整行按钮（带导出图标）。**仅邮箱登录**展示。

**流程**：先安全验证 → 再展示导出内容 Modal（同容器内切换步骤，或关闭后打开导出步，以原型为准；当前原型为同 Modal 内切换）。

**步骤 A · 安全验证**

| 身份验证器状态 | 验证方式 |
|---|---|
| **未绑定** | 邮箱验证码：说明文案（验证码发送至当前登录邮箱）→ 发送验证码 → 输入 6 位码 →「验证并继续」 |
| **已绑定** | 身份验证器动态码：输入 6 位 TOTP →「验证并继续」 |

验证失败：行内错误提示，不进入导出步。

**步骤 B · Export wallet**

| 区域 | 内容 |
|---|---|
| 标题 | Export wallet |
| 说明 | Copy either your private key or seed phrase to export your wallet. **Learn more**（外链或帮助页） |
| 安全提示 | Never share your private key or seed phrase with anyone.（醒目提示块） |
| Your wallet | 钱包地址缩略展示（如 `0x972...0E79`）+ **复制图标**（复制完整地址） |
| 操作按钮 | **Copy key**（复制私钥）、**Copy Phrase**（复制助记词/种子短语） |

**安全要求**

- 私钥与助记词仅在验证通过后展示/复制；不可在未验证状态露出。
- 复制敏感信息时可选二次确认（产品可选）；原型可直接复制并 Toast。
- 文案与入口使用英文标题「Export wallet」等与 Privy 导出体验对齐（按钮 Copy key / Copy Phrase 保持英文）。

##### 3\.5.8 充值 / 提现 / 划转（摘要）

下拉内「充值」「提现」「划转」按钮打开对应 Web 居中 Modal 或抽屉；登录方式差异（如钱包登录可走已连接钱包充提、邮箱登录以外部地址为主）及提现安全验证（钱包签名 / 邮箱+验证器）详见《[登录、划转与充提](https://ksgf73ukjokp.sg.larksuite.com/wiki/Rf9bwrHoNiU3ykkoa45lUacYgdb)》。本文档不重复表单字段与链上确认细节。

### 4\. 其他全局行为

- 所有带下拉菜单的控件（如“更多”、多语言、钱包）在鼠标移出触发器及面板区域后延迟收起，避免误操作。

- 响应式行为：导航栏在视口宽度过小时，部分菜单项可收纳至“更多”或汉堡菜单（后续迭代说明）。

- 点击 Logo 或导航链接导致的页面跳转，导航栏激活状态同步更新。
