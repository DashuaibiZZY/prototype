# 邀请合伙人无限层返佣系统 · 用户合伙人中心（App）

> **文档导航**：[总览](邀请合伙人无限层返佣系统.md) · [业务定义](邀请合伙人无限层返佣系统-业务定义.md) · [后台管理](邀请合伙人无限层返佣系统-后台管理.md) · [用户合伙人中心（Web）](邀请合伙人无限层返佣系统-用户合伙人中心Web.md) · [用户合伙人中心（App）](邀请合伙人无限层返佣系统-用户合伙人中心App.md)


**产品原型**：[App · 合伙人管理中心](https://dashuaibizzy.github.io/prototype/perp_dex/app/代理中心.html)

面向已开通合伙人资格的 App 登录用户，用于管理邀请链接、查看团队业绩、维护下级合伙人、查询佣金结算。对外文案统一使用「合伙人」，不使用「代理」。

**与「邀请返佣」页的关系**：App 端按角色在路由层分流——普通用户进入 `app/邀请返佣.html`；**合伙人用户从奖励页、个人中心等入口直接进入本页**，不展示邀请返佣占位态（详见《[邀请返佣（Web_APP）](邀请返佣（Web_APP）.md)》§App 页面路由）。

### 4\.0\.0 邀请返佣入口分流（App）

App 内凡标注为「邀请」类入口，客户端读取登录用户**是否为合伙人**后再决定跳转目标：

| 入口位置 | 普通用户 | 合伙人 |
|---|---|---|
| **首页** · 快捷入口「邀请」 | `app/邀请返佣.html` | `app/代理中心.html`（合伙人管理中心） |
| **个人中心** · 「邀请赚币」 | `app/邀请返佣.html` | `app/代理中心.html` |
| **奖励页** · 「邀请返佣」卡片 | 展示返佣比例、累计佣金与**等级进度**（如升级 Lv3）；点击进入 `app/邀请返佣.html` | 仍展示返佣比例与累计佣金；**不展示**等级进度条与「还差 N 位活跃好友」等升级文案；卡片底部可展示「合伙人管理中心 →」引导；点击进入 `app/代理中心.html` |

**说明**：

- 合伙人登录后，个人中心**不再重复**展示独立的「合伙人中心」入口（「邀请赚币」已跳转至本页）。
- 普通用户的奖励页邀请卡片保留 Lv 等级进度；合伙人用户的团队与链接管理均在合伙人中心完成，故奖励卡片仅作摘要入口。
- 原型：`app/首页.html` 状态 **③b**、`app/个人中心.html` 状态 **③**、`app/奖励.html` 原型按钮 **合伙人登录**（奖励页完整规则见《[App 端奖励页](../app/App 端奖励页.md)》§4.6）。

**与 Web 合伙人中心的关系**：业务口径、字段定义、结算规则、层级限制、停用/启用链接、比例调整确认等**均与 Web §3 一致**；本文仅描述 App 端信息架构与交互差异。未单独说明的字段含义、计算公式、后台对账关系，一律参照 Web 对应章节。

**App 相对 Web 的结构差异（速览）**：

| 维度 | Web | App |
|---|---|---|
| 主导航 | 左侧栏 3 项 + 二级「团队数据分析」 | 底部 **四 Tab**（数据独立 Tab） |
| 周期切换 | 各页页头内嵌 Tab / 按钮组 | 顶栏 **「周期」** → Bottom Sheet |
| 佣金筛选 | 页内日期选择 + 下拉 | 顶栏【筛选】→ Bottom Sheet |
| 列表 | 表格 + 分页 10 条/页 | 列表 + 下滑加载 5 条/批 |
| 下钻 | 子页面 / 弹窗 | **Stack 全屏子页**（返佣流水非弹窗） |
| 链接摘要 | 比例 + 上级 + 默认码 + 分享 | **仅**比例 + 使用中 N/50 |
| 创建链接 | 页头按钮 | 搜索框下 **+ 新增邀请链接** |
| 添加下级 | 表格上方按钮 | 搜索框下 **+ 添加下级合伙人**（仅下级 Tab） |

### 4\.0\.4 通用交互（继承 Web §3.0；App 特有项见说明列）

| 约定 | 说明 |
|---|---|
| 统计周期 | 各业务 Tab 支持 `1D` / `1W` / `1M` / `3M`（**不含 ALL**）；通过顶栏【周期】切换 |

| 排序 | App 列表**不提供**表头排序交互；默认顺序与 Web 各表默认排序一致（一般为时间或贡献额新→旧 / 高→低，以实现为准） |
| 复制 | 所有 UID、邀请码、邀请链接、钱包等支持一键复制；成功 Toast「已复制 {类型}」 |
| 地址展示 | UID 为主展示字段；钱包 / 邮箱为次要展示；钱包缩写（前 6 位 + … + 后 4 位），复制写入完整值 |
| 金额与数量 | 与 Web §3.0「金额与数量展示规则」完全一致 |
| 二次确认 | 见 §4.8；**禁止**使用系统浏览器弹窗 |
| 已移除能力 | 与 Web §3.8.2 相同：无独立「链接数据分析」页；无异常返佣倒挂修正入口 |

### 4\.0\.6 Tab 与状态保持

| 状态项 | 规则 |
|---|---|
| **各 Tab 独立周期** | 邀请链接 / 团队 / 数据 三个 Tab **分别记忆**各自选中的 `1D/1W/1M/3M`（默认均为 `1W`）；切换 Tab **不**互相覆盖 |
| **搜索词** | 各 Tab / Sub-Tab 独立记忆；切换 Tab 返回后保留 |
| **列表滚动位置** | 切换 Tab 后返回，尽量恢复离开前滚动位置（以实现为准） |
| **Stack 模式** | 进入 Stack 子页时 **禁止**切换 Hub Tab；须先返回 Hub |
| **佣金筛选** | 结算日期 + 状态筛选在佣金 Tab 内记忆；进入佣金详情再返回 **保留** |

### 4\.0\.7 Stack 子页导航

Hub 与 Stack **双层顶栏**：

| 层级 | 返回键 | 标题 |

| Hub | 顶栏左侧 → 退出合伙人中心 | 「合伙人中心」 |
| Stack | **子页顶栏**左侧 → 回上一层 | 子页标题 + 副标题 |

  └─ 团队穿透 L1
       └─ 团队穿透 L2 …（无限层，逐层 pop）

## 4\.1 邀请链接 Tab

**对应 Web**：§3.1 邀请链接管理

**页面作用**：创建多条邀请链接，按渠道追踪推广效果；管理备注、邀请码与链接启用状态。

### 4\.1\.1 页内摘要条

位于搜索框上方，**仅展示两项**（相较 Web §3.1.2 精简，不展示上级钱包、默认邀请码）：

| 字段 | 说明 |
|---|---|
| **返佣比例 X%** | 当前账号生效返佣比例（与 Web 侧栏「我的最高比例」口径一致；原型演示 70%） |
| **使用中 N/50** | 当前处于「使用中」的链接数量 / 上限 50 |

### 4\.1\.2 搜索与创建

| 元素 | 说明 |
|---|---|
| 搜索框 | placeholder「搜索备注或邀请码」；实时模糊匹配备注名称或 7 位邀请码 |
| **+ 新增邀请链接** | 位于搜索框**下方**（不在顶栏） |

**创建规则**（与 Web §3.1.4、§3.1.5 一致）：

- 使用中已达 **50** 时，点击创建 Toast 提示「使用中链接已达上限 50 个」，不打开 Sheet。
- Sheet 标题「创建邀请链接」；字段与校验：

| 字段 | 规则 |
|---|---|
| 备注名称 | **必填**；最长 **20 字**（与 Web 一致） |
| 邀请码 | **必填**；**7 位**大写字母或数字；不可与已有码重复；创建后不可修改 |
| 确认创建 | 提交创建 |

- **提交校验失败 Toast**：「请填写备注名称」/「邀请码须为 7 位字母或数字」/「邀请码已存在」/「使用中链接已达上限 50 个」。
- 提交成功后列表刷新，摘要条「使用中 N/50」+1，Toast「邀请链接已创建」；新链接状态为 **使用中**。

**修改备注 Sheet**（标题「修改备注」）：

| 字段 | 规则 |
|---|---|
| 备注名称 | 必填；预填当前值；邀请码不可见、不可改 |
| 保存 | 成功后 Toast「备注已更新」 |

### 4\.1\.2a 列表默认顺序

- 默认按**创建时间新→旧**排列（以实现为准）；搜索/filter 后仍保持该顺序。
- 停用链接**不**从列表移除，混排展示。

### 4\.1\.3 链接列表项

每条链接一条记录；**已停用**项仍展示，操作受限。

**列表项头部**

| 元素 | 说明 |
|---|---|
| 备注名称 | 旁侧状态：**使用中** / **已停用** |
| 邀请码 | 7 位码；支持复制 |
| 分享 | 分享入口 → 分享海报（码值随当前行）；**已停用**时不可用 |

**指标字段**（共 6 项，受顶栏【周期】筛选；口径与 Web §3.1.3 一致）：

| 指标 | 说明 |
|---|---|
| 直邀 | 该码归因直邀人数 |
| 下级合伙人 | 该码归因下级合伙人数 |
| 交易额 | 周期内该码伞下成交额（紧凑金额） |
| 手续费 | 周期内该码伞下手续费（精确金额，USDC） |
| 返佣 | 周期内合计返佣收入 |
| 净入金 | 周期内总净入金（可正可负，紧凑金额） |

**操作**（三项：复制链接 / 修改 / 停用或启用或默认占位）

| 按钮 | 规则 |
|---|---|
| **复制链接** | 完整 URL：`https://forx.finance/?ref={邀请码}`；**已停用**不可用 |
| **修改** | 打开「修改备注」Sheet；仅改备注，邀请码锁定；停用/使用中均可改 |
| **停用** / **启用** / **默认** | 见 §4.1.4 |

### 4\.1\.4 停用 / 启用 / 默认链接

业务定义、名额规则、二次确认文案与 Web §3.1.5 **完全一致**；App 差异仅为交互载体（确认对话框 + Toast，非 Web 模态框）。

| 场景 | App 行为 |
|---|---|
| 停用非默认链接 | 确认对话框标题「停用链接」，正文：`确认停用链接「{备注}」？停用后新用户将无法通过该链接注册。` → 确认后 Toast「链接已停用」 |
| 停用默认链接 | Toast「默认邀请链接不可停用」；操作位展示静态文案 **「默认」**，无【停用】 |
| 启用已停用链接 | 名额满 50 → Toast「使用中链接已达上限 50 个」；否则确认对话框标题「启用链接」，正文：`确认启用链接「{备注}」？启用后将占用一个使用中名额。` → Toast「链接已启用」 |
| 复制 / 分享 | 已停用项【复制链接】与分享不可用 |

列表仍展示已停用链接及其历史周期指标；下滑加载规则见 §4.0.4。

### 4\.1\.5 分享海报

- 触发：链接列表项分享入口（**使用中**可用；已停用不可用）。
- 展示**当前行邀请码**与二维码；规则与 App 邀请返佣 §分享海报弹窗一致（码值随入口变化）。
- 操作：**取消**（关闭）；**分享海报**（调起系统分享 / 保存图片）。
- 复制邀请码、复制链接成功 Toast 分别为「邀请码已复制」「邀请链接已复制」（或统一为「{类型}已复制」）。

## 4\.2 团队 Tab

**对应 Web**：§3.2 合伙人管理

**页面作用**：查看本人伞下业绩构成，管理直属下级合伙人与自邀直客。

### 4\.2\.1 我的身份

| 区域 | 说明 |
|---|---|
| 上级 | **上级 UID**（可复制）+ 上级钱包缩写 |
| 我的比例 | 当前生效比例（如 70%） |

一级合伙人时上级展示规则与 Web §3.2.2 一致（展示「一级代理」等特殊文案，以实现为准）。

### 4\.2\.2 核心 KPI

Web §3.2.3 的五项 KPI，App 合并为**同一区块**集中展示：

| 指标 | 说明 |
|---|---|
| 团队交易额 | 伞下总成交额；受【周期】影响 |
| 返佣收入 | 本期预估总返佣 |
| 团队人数 | 伞下总人数 |
| 交易人数 | 周期内交易用户数；**日级快照**，UTC+8 0 点更新 |
| 团队净入金 | 可正可负；**日级快照** |

**指标字段**

| 指标 | 说明 |

| 返佣 | **最终返佣**（调减后实发金额）；若存在违规扣减，另展示 **「违规 −$XX」** 入口（`XX` 为扣减绝对值），点击 → 说明对话框展示后台「佣金扣除原因说明」全文 |

**违规展示规则**（与 Web §3.5.5 一致）：

- 主行返佣金额 = **调减后实发**；违规入口展示扣减额；须点击可读原因全文（App 不用 hover）。
- 同一扣除原因在 **佣金详情 · 聚合 KPI · 违规扣除【查看说明】** 同步展示。

**操作**：【佣金详情】→ §4.6。**任意状态**（含待审核、零返佣日）均可进入佣金详情。

列表下滑加载，每批 5 条；默认排序 **结算日新→旧**。

后台「返佣停止」等特殊批次**不在**用户列表展示（与 Web §3.5.3 一致）。

### 4\.5\.4 与后台对账的对应关系

与 Web §3.5.5 **完全相同**：

| 后台事实 | 用户列表展示 | 筛选归类 |
|---|---|---|
| 等待对账 / 已拒绝 / 调减未放 / 冻结 | **待审核** | 待审核 |
| 已放款 | **已发放** | 已发放 |

- 四指标关系：`应发返佣 = 实发返佣 + 违规扣除`（有扣减时）。

### 4\.6\.3 当日返佣贡献列表

区块小标题「当日返佣贡献」。

**UID 列表项**（每条对应 Web 表格一行，按 UID 日汇总）：

| 区域 | 说明 |
|---|---|
| 头部 | UID（可复制）；钱包/邮箱；下级合伙人备注（如有）；类型 **下级** / **直客** |
| 指标 | **比例**（返佣 X% / 级差 X%）/ **交易额** / **手续费** / **返佣** |
| 操作 | 【交易返佣流水】→ §4.7 |

**数据聚合逻辑**与 Web §3.6.1 一致：

- 取选定结算日全部返佣明细，**按 UID 聚合**为一条。
- 同一 UID 当日多笔：交易额、手续费、返佣 **求和**。
- 类型标签：**下级** / **直客**；比例展示 `级差 X%` 或 `返佣 X%`。
- 默认排序：**返佣金额高→低**（与 Web 默认一致）。

**搜索与类型筛选**（Web §3.6.1 工具条）：

| 控件 | App 要求 |
|---|---|
| 搜索 | UID / 钱包 / 邮箱 模糊匹配（建议在「当日返佣贡献」标题下增加搜索框；原型若暂未展示，**上线须补齐**） |
| 类型筛选 | 全部 / 下级 / 直客（**上线须补齐**） |

列表下滑加载，每批 5 条；空态「该结算日暂无返佣明细」。

## 4\.7 交易返佣流水（Stack 子页）

**对应 Web**：§3.6.2（Web 为弹窗，App 为独立全屏页）

**进入**：佣金详情 → 某 UID【交易返佣流水】

### 4\.7\.1 顶栏

| 元素 | 说明 |
|---|---|
| 标题 | 「交易返佣流水」 |
| 副标题 | `{UID} · {结算日 YYYY-MM-DD} · 交易返佣流水` |
| 返回 | 子页顶栏左侧 → 回到佣金详情（**不**回到佣金 Tab） |

### 4\.7\.2 流水列表

每笔交易一条记录（Web 表格一行）：

| 字段 | 说明 |
|---|---|
| 交易时间 | `YYYY-MM-DD HH:mm:ss`，精确到秒 |
| 交易额 | 该笔成交名义金额 |
| 手续费 | 该笔手续费（USDC） |
| 比例 | 该笔适用 `返佣 X%` 或 `级差 X%` |

**规则**（同 Web §3.6.2）：

- 仅展示**当前结算日 + 当前 UID** 的明细。
- 按交易时间 **新→旧** 排序。
- 下滑加载，每批 5 条。
- 返回后仍停留在佣金详情页，**不丢失**结算日与 UID 上下文。
- 无数据：「暂无流水」。

## 4\.8 确认、说明与已移除能力

### 4\.8\.1 二次确认场景

与 Web §3.8.1 业务规则一致；App 使用确认对话框（标题 + 正文 + 【取消】【确认】）：

| 场景 | 说明 |
|---|---|
| 停用邀请链接 | 确认后新用户无法注册，历史数据保留 |

| 违规扣除说明 | 单按钮说明对话框，标题「违规扣除说明」，正文为后台配置全文，按钮【确认】 |

## 4\.10 合伙人层级限制（App 摘要）

与 Web §3.7、§1.4 **完全一致**：

- 平台对合伙人账号设最多 **10 层**合伙人层级（L1 为一级合伙人）。
- **添加下级合伙人**时，若会导致链路深度超过 10 层，系统**禁止绑定**并 Toast / 对话框提示。
- 该限制仅约束**新增发展**，不自动裁切已存在深层节点。
- 直客绑定、交易、返佣计算**不受**「10 层」约束。
