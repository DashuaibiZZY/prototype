# 消息中心 · 邀请返佣事件

> **Lark 主文档（消息中心对接以该文档为准）**：[消息中心 · 邀请返佣事件](https://ksgf73ukjokp.sg.larksuite.com/wiki/BiTown38EipLF3k8TJllGd35gHc)
>
> 本文件为仓库留痕副本，便于复制与 PR 评审。业务规则见《[邀请返佣（Web/APP）](邀请返佣（Web_APP）.md)》§3.1 等级快照与升级判断。
>
> **范围说明**：邀请返佣业务以下 4 类场景发送系统通知（站内信 / App Push 等由消息中心规则配置）。

---

## 事件目录（邀请返佣）

| 序号 | 事件 | 业务线 | 触发时机 |
|---|---|---|---|
| 1 | `invite_rebate.level.upgraded` | 邀请返佣 | 等级快照判定应升级，实时升级成功 |
| 2 | `invite_rebate.level.buffer.started` | 邀请返佣 | 每日 00:00（UTC+8）判定不达标，进入 7 日降级保护（第 1 天） |
| 3 | `invite_rebate.level.downgraded` | 邀请返佣 | 保护期第 8 日 00:00（UTC+8）仍不达标，执行降级 |
| 4 | `invite_rebate.reclaimed` | 邀请返佣 | 后台回收指令在次日 0:00（UTC+8）批次执行成功 |

> 事件目录只能新增，不能修改和替换；新版本在事件名后追加 `v` + 自然数（如 `invite_rebate.level.upgraded.v2`）。

## 系统事件传输字段与消息变量

### 1. 邀请等级升级 `invite_rebate.level.upgraded`

**允许消息模板使用的变量：**

```
{{ user_nickname }}
{{ previous_level }}
{{ current_level }}
{{ previous_rebate_ratio }}
{{ current_rebate_ratio }}
{{ active_friends }}
{{ direct_client_volume }}
{{ effective_at }}
{{ occurred_at }}
```

**消息示例：**

```
尊敬的 {{ user_nickname }}，恭喜您的邀请等级已升级。

原等级：Lv{{ previous_level }}（{{ previous_rebate_ratio }}%）
新等级：Lv{{ current_level }}（{{ current_rebate_ratio }}%）

当前活跃好友：{{ active_friends }} 人
下级累计交易量：{{ direct_client_volume }} USDT

新等级将于 {{ effective_at }}（UTC+8）起生效。
升级时间：{{ occurred_at }}
```

**默认配置：**

- 分类：业务通知
- 风险等级：普通
- 接收人：邀请返佣用户
- 建议渠道：站内信、App Push
- 触发时机：每日 00:00（UTC+8）等级快照后，若应属等级高于当前等级，则实时升级并通知
- 幂等依据：用户 UID + 升级批次日期 + 目标等级

### 2. 降级保护开启 `invite_rebate.level.buffer.started`

**允许消息模板使用的变量：**

```
{{ user_nickname }}
{{ current_level }}
{{ current_rebate_ratio }}
{{ target_level }}
{{ target_rebate_ratio }}
{{ buffer_end_at }}
{{ active_friends }}
{{ active_friends_required }}
{{ direct_client_volume }}
{{ direct_client_volume_required }}
{{ occurred_at }}
```

**消息示例：**

```
尊敬的 {{ user_nickname }}，您的邀请等级保护已开启。

近期活跃好友或交易量暂未达标，我们将为您保留当前返佣比例 7 天，请抓紧邀请好友交易吧。

当前等级：Lv{{ current_level }}（{{ current_rebate_ratio }}%）
保护期至：{{ buffer_end_at }}（UTC+8）

若到期仍未恢复条件，返佣比例将从 {{ current_rebate_ratio }}% 降至 {{ target_rebate_ratio }}%。

当前活跃好友：{{ active_friends }} / {{ active_friends_required }}
下级累计交易量：{{ direct_client_volume }} / {{ direct_client_volume_required }} USDT

开启时间：{{ occurred_at }}
```

**默认配置：**

- 分类：业务通知
- 风险等级：普通
- 接收人：邀请返佣用户
- 建议渠道：站内信、App Push
- 触发时机：每日 00:00（UTC+8）等级快照判定不满足当前等级门槛，进入 7 日缓冲期第 1 天
- 幂等依据：用户 UID + 缓冲期开始日期

> **不发通知**：缓冲期第 5 天、第 7 天的倒计时提醒本期不做系统通知。

### 3. 邀请等级确定降级 `invite_rebate.level.downgraded`

**允许消息模板使用的变量：**

```
{{ user_nickname }}
{{ previous_level }}
{{ current_level }}
{{ previous_rebate_ratio }}
{{ current_rebate_ratio }}
{{ effective_at }}
{{ occurred_at }}
```

**消息示例：**

```
尊敬的 {{ user_nickname }}，您的邀请等级已调整。

返佣比例已从 {{ previous_rebate_ratio }}% 调整为 {{ current_rebate_ratio }}%。
继续邀请好友提升交易量，随时可以升回来。

原等级：Lv{{ previous_level }}（{{ previous_rebate_ratio }}%）
新等级：Lv{{ current_level }}（{{ current_rebate_ratio }}%）
生效时间：{{ effective_at }}（UTC+8）

调整时间：{{ occurred_at }}
```

**默认配置：**

- 分类：业务通知
- 风险等级：普通
- 接收人：邀请返佣用户
- 建议渠道：站内信、App Push
- 触发时机：降级保护期第 8 日 00:00（UTC+8），仍不满足条件，执行降级
- 幂等依据：用户 UID + 降级执行日期

### 4. 待结算回收 `invite_rebate.reclaimed`

**允许消息模板使用的变量：**

```
{{ user_nickname }}
{{ reclaim_amount }}
{{ currency }}
{{ reclaim_reason }}
{{ executed_at }}
{{ remaining_pending }}
{{ reclaim_instruction_id }}
{{ occurred_at }}
```

**消息示例：**

```
尊敬的 {{ user_nickname }}，您的邀请返佣待结算金额已调整。

回收待结算金额：{{ reclaim_amount }} {{ currency }}
回收原因：{{ reclaim_reason }}
执行时间：{{ executed_at }}（UTC+8）

调整后剩余待结算返佣：{{ remaining_pending }} {{ currency }}

如有疑问，请联系在线客服或查看邀请返佣页「待结算收益」说明。
```

**默认配置：**

- 分类：业务通知
- 风险等级：较高
- 接收人：被回收 UID
- 建议渠道：站内信、App Push
- 触发时机：运营在后台提交回收指令后，**次日 0:00（UTC+8）日结批次执行成功时**（提交瞬间不发）
- 幂等依据：回收指令 ID（`reclaim_instruction_id`）

> **说明**：批次执行失败（如待结算余额不足）时不发送通知、不写入用户端回收记录。

## 变量说明

| 变量 | 说明 |
|---|---|
| `previous_level` / `current_level` | 邀请等级 Lv0–Lv3 |
| `previous_rebate_ratio` / `current_rebate_ratio` | 返佣比例（10 / 15 / 20 / 25） |
| `target_level` / `target_rebate_ratio` | 保护期结束后若仍不达标，预计降至的等级与比例 |
| `active_friends` | 30 日内交易额 ≥ $10k 的好友数 |
| `active_friends_required` | 当前等级门槛要求的活跃好友数 |
| `direct_client_volume` | 下级累计交易量（USDT） |
| `direct_client_volume_required` | 当前等级门槛要求的累计交易量 |
| `buffer_end_at` | 7 日保护期结束时间（UTC+8） |
| `effective_at` | 等级变更生效时间（UTC+8） |
| `reclaim_amount` / `reclaim_reason` | 回收金额与原因（运营在后台填写） |
| `remaining_pending` | 回收后剩余待结算返佣 |
| `reclaim_instruction_id` | 回收指令 ID |
| `occurred_at` | 事件发生时间（UTC+8） |
