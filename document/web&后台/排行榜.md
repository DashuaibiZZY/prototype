# 一、Web 端排行榜页

**原型**：[https://dashuaibizzy.github.io/prototype/perp_dex/排行榜.html](https://dashuaibizzy.github.io/prototype/perp_dex/排行榜.html)

## 1\.1 功能定位

展示平台交易者的综合表现排名，支持按多个维度查看与排序。用户可了解自身在全站榜单中的位置，并按 **UID / 钱包 / 邮箱** 搜索其他交易者。

当前支持四个排名维度：

|维度|字段|说明|
|---|---|---|
|收益金额|PnL|统计周期内已实现盈亏金额（USDT）|
|收益率|ROI|统计周期内投资回报率（%）|
|交易额|Volume|统计周期内合约成交额（USDT 名义价值）|
|积分|Points|统计周期内获得的平台积分|

### 1\.7.1 列定义

|列名|对齐|说明|
|---|---|---|
|排名|居中|当前排序维度下的名次；Top 1–3 使用徽章样式（黑/深灰/浅灰）|
|交易者|左对齐|**UID 加粗**；钱包地址缩写或邮箱位于下方灰色小字（有则展示）|
|收益金额 (PnL)|右对齐|带正负号，盈利绿色，亏损红色|
|收益率 (ROI)|右对齐|百分比，涨绿跌红|
|交易额 (Volume)|右对齐|USDT 名义成交额，大额可用 K/M/B 缩写，琥珀色强调|
|积分|右对齐|整数展示|

### 1\.7.2 排序规则

- 表头 PnL、ROI、交易额、积分均可点击排序。

- 默认排序维度：**收益率 (ROI)** 降序（当前选中列高亮为黑色）。

- 点击列头切换升序/降序；再次点击另一列则切换排序维度。

- 排名列数值随当前排序维度重新计算。

### 1\.7.3 行交互

- 行 hover 浅灰背景。

- Top 3 排名徽章与后续纯数字排名样式区分。

### 1\.7.4 数据展示规则

- PnL：保留两位小数，正数带「+」前缀。

- ROI：保留两位小数，带「%」。

- 交易额：按平台统一金额格式；建议使用 K/M 缩写（如 $128.6M）。

- 积分：千分位分隔，无小数。

# 二、后台管理：排行榜虚拟用户数据配置

**原型（列表）**：[排行榜虚拟用户数据配置](https://dashuaibizzy.github.io/prototype/perp_dex/admin/排行榜后台.html)

**原型（配置子页）**：列表页点击「+ 新增配置」进入（URL `#batch`）；行内「编辑」进入（URL `#edit={id}`）

> **变更说明（相对旧版「影子配置」）**：已移除影子账户、目标排名区间、生命周期、调度引擎等逻辑。运营为排行榜 **虚拟用户**（非真实注册用户）配置假榜单数据；后端按 **数据写入时间** 聚合，用户在 Web 端 **7D / 30D** 视图中可见。

## 侧栏结构

后台采用 **ForX Admin 统一侧栏**（见《[后台权限与人员管理](后台权限与角色管理.md)》§3）。

| 侧栏入口 | 页面 |
|---|---|
| 排行榜用户数据配置 | **列表页** + **配置子页**（新增/编辑共用） |

**权限**（v3）：「排行榜用户数据配置」**写** = 可新增/编辑虚拟用户配置；**读** = 仅查看。无敏感组。详见 §4.4。原型 **全量展示**。

## 2\.1 功能定位

运营后台用于为排行榜 **虚拟用户** 配置假榜单数据。**不可**为平台真实注册用户配置。

流程如下：

1. **指定虚拟用户**：手动输入虚拟 UID，或选择「保存时生成」（UID 在保存成功后才展示）。
2. **选择榜单范围**：全平台，或关联某一 **平台活动** 的子榜单。
3. **填写指标**：按范围展示对应输入项（见 §2.5.4）。
4. **保存**：后端记录 **数据时间**；在 7D / 30D 等统计窗口内可见并参与排名。

新增与编辑均使用 **同一配置子页**（表格形式）：默认 **1** 条明细，运营可添加至最多 **10** 条；共享榜单范围与生效策略。配置保存后 **不可停用**。

本模块支持两类 **榜单范围**：

|榜单范围|说明|
|---|---|
|全平台|四项指标（PnL / ROI / Volume / 积分）均可配置，**默认均为 0**|
|平台活动|用户仅参与 **已选活动** 的交易大赛排行榜；**仅展示** 活动已启用的排序维度对应输入框|

### 2\.1.1 活动关联与可选范围

**活动下拉可选条件**（须同时满足）：

|条件|说明|
|---|---|
|活动状态 = 进行中|已结束、未开始等活动 **不出现在** 下拉列表|
|已开启排行榜|活动「交易大赛配置」中排行榜模块为启用状态|

数据来源：活动上架管理系统 · 交易大赛配置。

选择活动后，弹窗 **只读展示** 该活动当前 **排序维度**（交易额 / 收益率 / 收益金额，与活动「榜单配置」中 **已启用** 项一致）。

- 保存时 **不覆盖** 活动本身的排序规则；运营仅填数值。
- 配置指标区 **仅渲染** 活动支持的维度字段，不展示未启用项。

## 2\.2 页面结构

采用 **列表 + 子页** 导航（非弹窗），支持浏览器返回与 URL hash：

|视图|入口|说明|
|---|---|---|
|**列表页**|侧栏默认进入|筛选条、虚拟用户配置列表、分页|
|**配置子页**|「+ 新增配置」/ 行内「编辑」|新增默认 1 条、可增至 10 条；编辑时为单条|

列表页顶栏仅 **+ 新增配置**；子页顶栏提供 **← 返回列表**、**保存**。

## 2\.3 筛选条

支持与列表联动筛选，点击「筛选」应用条件，「重置」清空。

|筛选项|说明|
|---|---|
|UID / 钱包 / 邮箱|关键词模糊搜索|
|榜单范围|全部 / 全平台 / 平台活动|
|活动名称|选择「平台活动」后启用|

## 2\.4 配置用户列表

### 2\.4.1 表头字段

|列名|说明|
|---|---|
|UID / 标识|虚拟 UID + 钱包占位；带 **虚拟** 标签|
|榜单范围|全平台，或「平台活动 + 活动名称」|
|配置指标|按范围展示已配置项（全平台四项；活动仅对应维度）|
|活动排序维度|仅活动范围：只读展示活动启用的排序字段|
|数据时间|数据写入时间；次行展示生效策略（立即 / 预约日期）|
|操作|编辑|

### 2\.4.2 操作

- **新增配置**：进入配置子页，默认 1 条明细，可添加至 10 条。

- **编辑**：进入配置子页（虚拟 UID、榜单范围只读；**生效策略不可修改**；不可添加行；交易额、积分仅可上调）。

- **不可停用**：模拟数据配置后持续参与榜单，不提供停用操作与状态字段。

### 2\.4.4 列表分页

列表底部统一分页器（见《[后台权限与人员管理](后台权限与角色管理.md)》§3.1）：每页 **10 条**；筛选后回到第 1 页。

## 2\.5 配置子页（新增 / 编辑共用）

### 2\.5.1 虚拟用户 UID

|方式|说明|
|---|---|
|手动输入 UID|运营输入虚拟 UID；**不可**填写真实注册用户 UID，保存前校验|
|保存时生成（新增默认）|选择后占位「保存后分配 UID」；**点击保存后** 系统创建虚拟用户并分配 UID|

- 列表与保存成功提示中展示最终 UID。
- **编辑态**：UID 只读，不可重新生成或修改；榜单范围、活动选择、**生效策略**亦只读；**不可添加配置行**。

**虚拟用户约束**：

- 本模块 **仅服务排行榜虚拟用户**（系统标记 `isVirtual`，用于假榜单数据）。
- **禁止**为真实注册用户配置；输入真实 UID 时阻止保存。

### 2\.5.2 榜单范围

双选项切换（**编辑态禁用**）：

|选项|行为|
|---|---|
|全平台（默认）|展示 PnL、ROI、Volume、**积分** 四项输入，**默认值均为 0**|
|平台活动|可搜索下拉选择活动（见下）；**仅展示** 活动支持的指标输入框|

**活动选择控件**：

- 样式：**可搜索下拉框**（点击展开 → 顶部搜索框过滤 → 点击选项选中）。
- 可选列表：**进行中** 且 **已开启排行榜** 的活动；其余活动不可选。
- 保存校验：选择「平台活动」但未选活动时，提示「请选择活动」。

### 2\.5.3 数据时间与统计窗口

**运营侧不提供周期类型选择**（无日榜 / 周榜 / 月榜选项）。

|项|说明|
|---|---|
|数据时间|保存（或预约生效到达）时由后端写入的时间戳|
|统计归属|后端按该时间戳落入 Web 端 **7D / 30D** 等滚动窗口参与聚合与排名|
|可见性|例如配置写入时间为 8 月 25 日，则在 8 月 31 日查看 **7D** 榜单时可见该用户|

- 同一用户在同一榜单范围下 **仅保留一条配置**；编辑为覆盖更新。
- 列表「数据时间」列展示写入时间；预约生效待入库时显示「—」。

### 2\.5.4 配置指标

**全平台**

|字段|类型|默认值|说明|
|---|---|---|---|
|收益金额 (PnL)|数字，USDT|**0**|可正可负；编辑可自由调整|
|收益率 (ROI %)|数字，%|**0**|编辑可自由调整|
|交易额 (Volume)|数字，USDT 名义|**0**|编辑 **仅可上调**（不可低于原值）|
|积分 (Points)|整数|**0**|编辑 **仅可上调**（不可低于原值）|

- 四项 **均展示**，初始 **均为 0**；运营按需修改后保存。

**平台活动**

|规则|说明|
|---|---|
|字段范围|**仅展示** 该活动在「榜单配置」中 **已启用** 的排序维度对应输入框|
|示例|活动仅启用「交易额」→ 只出现 Volume 一项|
|未启用维度|不展示、不要求填写、不入库|
|积分|活动子榜 **不包含** 积分配置项|

### 2\.5.5 生效策略

|选项|说明|
|---|---|
|立即生效（默认）|保存后立即写入数据时间并参与当前统计窗口内的排名|
|指定生效日期|选择 **不早于今天** 的日期；到达该日 00:00（服务端时区）后写入数据时间|

**编辑态**：生效策略 **只读展示**，不可切换或修改日期。

### 2\.5.6 配置明细表

|规则|说明|
|---|---|
|默认行数|新增时默认 **1** 条，运营点击「添加一行」追加|
|单次上限|**最多 10 条**（编辑时为单条，不可追加）|
|共享项|榜单范围、生效策略|
|每行独立|虚拟 UID 方式、各指标数值|
|删除|至少保留 1 行；编辑态无删除列、**无「添加一行」按钮**|

### 2\.5.7 保存与校验

- 「保存」：校验通过后写入后端；若选择「保存时生成」，成功后提示展示新 UID。
- 「取消」/「返回列表」：不保存并回到列表页。
- 任一行 UID 为空（且非「保存时生成」）→ 阻止保存并提示行号。
- 任一行 UID 为真实用户 → 阻止保存。
- 本批次内 UID 重复 → 阻止保存。
- 活动榜未选活动 → 阻止保存。
- **编辑**：交易额、积分低于原值 → 阻止保存。

## 2\.8 弹层叠放规范（后台）

活动可搜索下拉须盖住下方内容；子页内下拉展开时点击外部收起。

# 三、Web 端与后台的数据关系

|项目|Web 排行榜页|后台虚拟用户配置|
|---|---|---|
|用户类型|真实交易者|仅 **虚拟用户**（假数据账号）|
|统计维度|PnL、ROI、交易额、积分|全平台榜可配置四项；活动子榜按活动启用维度配置|
|榜单范围|全平台公开榜单|全平台 或 指定活动子榜|
|周期|Web 当前为 7D / 30D 展示|后台按 **数据写入时间** 落入 7D / 30D 等窗口；**无需**运营选择周期类型|
|交易额口径|周期内合约成交额（USDT）|同左|
|排名更新频率|每 5 分钟（前端展示）|保存后下一刷新周期生效|
|Top 展示上限|前 1,000 名|与真实用户同一规则|

# 四、附录：活动榜单与全平台榜单的区别

**全平台榜单**

- 统计所有符合条件的真实用户 + 后台配置的 **虚拟用户**。

- Web 端默认展示此榜单。

**平台活动榜单**

- 仅统计已报名该活动的用户 + 绑定该活动的 **虚拟用户**。

- 活动详情页内的交易大赛排行榜与后台「平台活动」范围对应；**排序维度只读继承活动配置**。

- 同一配置用户在同一活动下仅一套生效配置。
