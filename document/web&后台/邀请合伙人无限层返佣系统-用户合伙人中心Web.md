# 邀请合伙人无限层返佣系统 · 用户合伙人中心（Web）

> **文档导航**：[总览](邀请合伙人无限层返佣系统.md) · [业务定义](邀请合伙人无限层返佣系统-业务定义.md) · [后台管理](邀请合伙人无限层返佣系统-后台管理.md) · [用户合伙人中心（Web）](邀请合伙人无限层返佣系统-用户合伙人中心Web.md) · [用户合伙人中心（App）](邀请合伙人无限层返佣系统-用户合伙人中心App.md)


**产品原型**：[合伙人中心](https://dashuaibizzy.github.io/prototype/perp_dex/代理中心.html)

面向已开通合伙人资格的登录用户，用于管理邀请链接、查看团队业绩、维护下级合伙人、查询佣金结算。对外文案统一使用「合伙人」，不使用「代理」。

**与「邀请返佣」页的关系**：普通邀请返佣页面向非合伙人用户；**合伙人用户登录后应进入本中心**。若强行打开邀请返佣页，展示占位并引导跳转至合伙人中心（见《[邀请返佣（Web_APP）](邀请返佣（Web_APP）.md)》）。

### 金额与数量展示规则

| 场景 | 规则 |
|---|---|
| **紧凑金额**（交易额、净入金等） | ≥10 亿 `$X.XXB`；≥100 万 `$X.XXM`；≥1 千 `$X.XXK`；否则 `$X.XX`；负数前缀 `-` |
| **精确金额**（返佣、**手续费(USDC)**） | 绝对值 ≥1000 → 整数千分位；否则保留 2 位小数 |
| **纯数量**（人数） | 四舍五入整数 + 千分位 |
| **环比**（团队数据分析 KPI） | `+$增量 (+X% vs 上周期)` / `- $增量 (-X% vs 上周期)`；上涨绿色、下跌红色；**团队人数**环比仅展示正增长 |
| **手续费列** | 凡列表含「交易额」类字段，其**右侧**均展示 **手续费(USDC)** 列 |
| **团队交易人数** | 字段名带虚线下划线；悬停提示「交易用户数据每天 UTC+8 0 点更新」。**后端按自然日快照，1 日最多录入 1 条**（见 §3.3.4） |
| **团队净入金** | 字段名带虚线下划线；悬停提示「团队净入金数据每天 UTC+8 0 点更新」。**后端按自然日快照，1 日最多录入 1 条**（见 §3.3.4） |

### 3\.1\.4 创建 / 修改邀请链接弹窗

页面截图：[**Web · 创建邀请链接弹窗**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/%E5%90%88%E4%BC%99%E4%BA%BA/web-modal-referral-link.png)

| 字段 | 规则 |
|---|---|
| 备注名称 | **必填**，最长 20 字，实时字数计数 |
| 自定义邀请码 | **创建时必填**；**必须 7 位**字母或数字；不可重复；创建后不可修改 |
| 提交 | 创建成功后列表刷新；修改模式仅保存备注 |

**创建前置校验**（与 §3.1.5 名额规则联动）：

- 点击页头【+ 創建新連結】时，若使用中链接已达 **50**，按钮本身已禁用；若仍触发创建入口，弹窗提示：「使用中链接已达上限 50 个，请先停用其他链接后再创建。」
- 提交创建时再次校验名额；通过后新链接状态为 **使用中**，页头计数即时 +1。

### 3\.1\.5 停用 / 启用链接（新增能力）

**业务定义**：

| 概念 | 说明 |
|---|---|
| **使用中** | `disabled = false`；占用「使用中名额」；新用户可通过该邀请码注册并归因 |
| **已停用** | `disabled = true`；**不占用**使用中名额；新用户无法通过该码注册 |
| **使用中名额** | 同时处于「使用中」的链接数量，上限 **50** |

**停用规则**：

| 规则 | 说明 |
|---|---|
| 默认链接 | 系统默认邀请链接（`isDefault = true` 且使用中）**不可停用**；点击【停用】时阻断并提示：「默认邀请链接不可停用。」 |
| 二次确认 | 非默认链接点击【停用】后弹出确认框，文案：`确认停用链接「{备注}」（{邀请码}）？停用后新用户将无法通过该链接注册，历史数据保留。` |
| 停用效果 | 状态变为「已停用」；**【复制链接】【分享海报】禁用**；历史直邀人数、交易额、手续费、返佣、净入金等**全部保留**且仍随周期筛选变化 |
| 名额释放 | 停用成功后，使用中计数 −1，页头【+ 創建新連結 (使用中 N/50)】同步更新 |

**启用规则**：

| 规则 | 说明 |
|---|---|
| 名额校验 | 启用前检查使用中数量；若已达 **50**，阻断并提示：「使用中链接已达上限 50 个，请先停用其他链接后再启用。」 |
| 二次确认 | 通过名额校验后弹出确认框，文案：`确认启用链接「{备注}」（{邀请码}）？启用后将占用一个使用中名额，新用户可通过该链接注册。` |
| 启用效果 | 状态变为「使用中」；复制、分享海报恢复可用；占用 1 个使用中名额 |

**与创建入口的联动**：

```
使用中 < 50  →  【+ 創建新連結】可点；任意非默认链接可【启用】
使用中 = 50  →  创建按钮禁用；仅可通过【停用】其他链接释放名额后再创建/启用
默认链接     →  始终占用 1 个名额且不可停用，保证至少有一条可用邀请入口
```

**操作入口汇总**：

| 场景 | 入口 | 结果 |
|---|---|---|
| 停用普通链接 | 列表行【停用】 | 确认 → 已停用 |
| 停用默认链接 | 操作列「默认」占位 | 阻断提示 |
| 启用已停用链接 | 列表行【启用】 | 名额校验 → 确认 → 使用中 |
| 达上限仍要新建 | 【+ 創建新連結】 | 阻断提示 |
| 达上限仍要启用 | 列表行【启用】 | 阻断提示 |

## 3\.3 团队数据分析

**访问路径**：侧栏 → 合伙人管理 → **团队数据分析**

**页面作用**：从**本人伞下团队**维度（与 §3.2 合伙人管理同源数据，**非**邀请链接 / 邀请码维度）查看 KPI 环比、历史趋势、三来源占比与 Top10 贡献排行。链接维度指标仍在 §3.1 列表按行查看。

页面截图：[**Web · 团队数据分析**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/%E5%90%88%E4%BC%99%E4%BA%BA/web-analytics-page.png)（若尚未上传，以原型为准）

### 3\.3\.1 页头与导航

| 元素 | 说明 |
|---|---|
| 标题 | 「团队数据分析」 |
| 副标题 | 「按指标查看来源分布与贡献排行。」 |
| 【← 返回合伙人管理】 | 回到 §3.2 合伙人管理；**不**保留独立 URL |
| 周期选择器 | 页头右侧 `1D` / `1W` / `1M` / `3M`；默认 `1W`；切换后**整页** KPI、图表、分布、排行同步刷新 |

**侧栏高亮**：进入本页时，「合伙人管理」保持一级选中态，「团队数据分析」二级子项高亮（`partner-nav-sub-active`）。

**数据范围**：统计口径与 §3.2 合伙人管理 overview **一致**——本人 + 直属直客 + 下级合伙人伞下（含级差归因）；**不按邀请码拆分**。

### 3\.3\.2 顶部 KPI（5 项 + 环比）

五张 KPI 卡横向排列，字段与 §3.2.3 对齐，并**额外**展示环比：

| KPI | 主值 | 环比副行 |
|---|---|---|
| 团队交易额 | 伞下总成交额 | `+$增量 (+X% vs 上周期)` 或 `-$增量 (-X% vs 上周期)`（涨绿跌红） |
| 返佣收入 | 本期预估总返佣 | 同上 |
| 团队人数 | 伞下总人数 | `+N (+X% vs 上周期)`（**仅正增长**演示） |
| 团队交易人数 | 周期内交易用户数 | 可正可负；**日级快照** |
| 团队净入金 | 正负着色 | 可正可负；**日级快照** |

- 环比文案格式：`+$1.2M (+12.5% vs 上周期)` / `-$420 (-3.2% vs 上周期)`；增量为 0 时「较上周期持平」。
- 页头周期切换时，五张卡主值与环比一并重算；不同周期 mock 可呈现涨跌组合（除团队人数外）。

### 3\.3\.3 维度 Tab（5 个）

位于 KPI 下方大卡片区顶栏；右侧展示当前周期标签（如 `1W`）。

| Tab | 对应指标 | 说明 |
|---|---|---|
| **团队交易额** | vol | 默认选中 |
| **返佣收入** | rebate | |
| **团队人数** | users | 累计人数，非周期交易人数 |
| **团队交易人数** | traders | 周期内活跃交易用户；**后端 1 日 1 条** |
| **团队净入金** | net | 支持正负；**后端 1 日 1 条** |

切换 Tab **仅切换下方三块内容**，不改变页头 KPI 与周期；每个 Tab 结构相同，指标口径随 Tab 变化。

### 3\.3\.4 每个维度下的三块内容

#### （1）数据趋势

| 维度 | 图表类型 | 图例（三来源） |
|---|---|---|
| 团队交易额 / 返佣收入 / 团队人数 | **堆叠面积图** | 自己产生 / 直属直客 / 合伙人级差 |
| 团队交易人数 | **堆叠面积图** | 同上（**日级数据**，见下表） |
| 团队净入金 | **正负多折线图**（Y 轴含 0 线） | 同上三来源，各线可正可负（**日级数据**，见下表） |

**横轴粒度**（随统计周期变化）：

| 周期 | 团队交易额 / 返佣收入 / 团队人数 | 团队交易人数 / 团队净入金 |
|---|---|---|
| `1D` | 按 **1 小时**（1h K 线粒度，最多 24 个点） | **仅 1 个数据点**（当日汇总；后端 1 日 1 条，**无小时级拆分**） |
| `1W` | 按天 | 按天（每日 1 点） |
| `1M` / `3M` | 按更长区间 | 按更长区间（仍为 **1 日 1 条** 串联） |

**团队交易人数、团队净入金 · 日级数据说明**（与交易额/返佣/人数等指标的 hourly 粒度不同）：

| 项 | 说明 |
|---|---|
| 录入频率 | 后端对这两项**最多按自然日录入 1 条** snapshot |
| 更新时间 | 每天 **UTC+8 0 点**更新（与前述卡片/列表虚线提示一致） |
| `1D` 周期下的趋势图 | 因无小时级数据，横轴**不会出现 1h 折线**；仅展示**当日 1 个汇总点**（或等价单日展示）。`1W` / `1M` / `3M` 下每个自然日对应 1 个点 |
| 原型说明 | 原型演示图表可能仍绘制连续折线/面积形态，**业务与接口以日级 1 日 1 条为准** |

- 图例颜色：自己产生（浅蓝）/ 直属直客（蓝）/ 合伙人级差（深蓝），与来源分布进度条一致。

#### （2）来源分布

三行进度条，展示当前 Tab 指标在三来源间的**绝对值 + 占比**：

| 来源标签 | 含义 |
|---|---|
| **自己产生** | 合伙人本人交易 / 返佣 / 入金等 |
| **直属直客** | 本人直接邀请、未升级为合伙人的用户 |
| **合伙人级差** | 下级合伙人伞下产生的级差收入 / 交易额等 |

每行格式：`{标签}` — `{数值} ({占比}%)` + 彩色进度条。

#### （3）贡献排行 · Top 10

左右两列并排：

| 左列 | 右列 |
|---|---|
| **直属直客 · Top 10** | **合伙人 · Top 10** |
| 列：# / UID / 指标值 | 列：# / UID·备注 / 指标值 |

**排行指标随当前 Tab 变化**：

| Tab | 直客排序字段 | 合伙人排序字段 |
|---|---|---|
| 团队交易额 | 累计交易额 | 总交易额 |
| 返佣收入 | 返佣金额 | 贡献级差收入 |
| 团队人数 | —（本 Tab 仅合伙人侧有人数意义时按总用户） | 总用户数 |
| 团队交易人数 | — | 交易用户数 |
| 团队净入金 | 净入金 | 净入金 |

- 合伙人列 UID 下可展示备注子行；UID / 备注均支持复制。
- 直客列展示 UID（可复制）。
- 无数据时展示「暂无数据」。

| **手续费(USDC)** | 该结算日伞下手续费合计；可排序 |
| 返佣金额 | 该日**最终返佣**（调减后为实发金额）；可排序；若有违规扣减，主行下方展示红色 **违规 −$XX**（**虚线**，悬停见后台配置的扣除原因） |

### 3\.5\.4 表格展示 vs 筛选项

用户侧刻意区分「表格展示文案」与「筛选归类文案」：

| 表格「状态」列展示 | 筛选项 | 业务含义 |
|---|---|---|
| **待审核**（琥珀） | 待结算 | 尚未放款：对账中、拒绝重算、调减未放、冻结暂停等（§1.5） |
| **已发放**（绿色） | 已结算 | 已审核并完成放款 |

筛选「待结算」仅展示状态为 pending 的行；「已结算」仅展示 settled 行。

### 3\.5\.5 与后台对账的对应关系

| 后台事实 | 用户流水展示 | 筛选归类 |
|---|---|---|
| 等待对账 / 已拒绝 / 调减未放 / 冻结 | **待审核** | 待结算 |
| 已放款 | **已发放** | 已结算 |

**违规调减展示**：若该结算日存在违规扣减，返佣金额列**主行**展示**调减后最终返佣**；次行 **违规 −$XX** 带虚线下划线，鼠标悬停展示后台「佣金扣除原因说明」。实发以放款结果为准（§1.5、§2.6）。同一扣除原因在 **§3.6 佣金详情** 聚合卡与扣除原因文案中同步展示。

### 3\.5\.6 下钻入口

1. 进入 §3.6 **佣金详情**子页（非侧栏新入口）。
2. 侧栏仍高亮 **佣金管理**。
3. 带入该 **结算日期**；重置 UID 搜索、类型筛选为「全部」、汇总表页码为第 1 页。

### 3\.6\.2 交易返佣流水（弹窗）

**进入**：佣金详情汇总行【交易返佣流水】

**表格列**：

| 列名 | 说明 |
|---|---|
| 交易时间 | 精确到秒 |
| 交易金额 | 该笔成交名义金额 |
| **手续费(USDC)** | 该笔手续费 |
| 返佣比例/级差比例 | 该笔适用比例 |
| 返佣金额 | 该笔产生的返佣/级差 |

**规则**：

- 仅展示**当前结算日 + 当前 UID** 的明细；按交易时间 **新→旧** 排序。

### 3\.6\.3 字段口径对照（三级）

| 层级 | 时间粒度 | 主体粒度 | 核心金额字段 |
|---|---|---|---|

| 交易返佣流水 | 交易时间 | 单笔成交 | 交易金额、手续费、返佣金额 |

三级均遵循 §3.0 约定：**凡含交易额类字段，其右侧均有手续费(USDC) 列**。

## 3\.7 合伙人层级限制（摘要）

与 §1.4 一致：

- 平台对合伙人账号设置**最多 10 层**合伙人层级（L1 为一级合伙人，向下至多 10 层合伙人节点）。
- 合伙人**新增下级合伙人**时，若会导致链路深度超过 10 层，系统**禁止绑定**新下级。该限制约束的是**新增发展**，不自动裁切已存在的深层节点。
- 直客绑定、交易、返佣计算不受「10 层」约束（直客不计入合伙人层数）。
