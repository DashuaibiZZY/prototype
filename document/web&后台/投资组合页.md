# 投资组合页

## 页面概述

- 页面名称：投资组合 / 个人中心（https://dashuaibizzy\.github\.io/prototype/perp\_dex/%E6%8A%95%E8%B5%84%E7%BB%84%E5%90%88\.html）

- **交互原型**：页面采用纵向全宽画框平铺（见 `投资组合.html`），含未登录、已登录、充提 Tab、VIP 弹窗等独立状态，供 UI 对照。

- 核心功能：

    - 提供账户总净资产、分类余额及今日盈亏的一站式概览

    - 展示 VIP 等级、费率优惠及升级路径

    - 多维度的合约账户表现分析（实时风险、累计数据、三线趋势图）

    - 提供充值、提现、资金划转的快捷操作入口

    - 底部聚合持仓、订单与资金流水明细，支持多标签页浏览

- 业务价值：让用户直观掌握资产全貌、交易表现、费率优惠与升级差距，驱动用户提升交易活跃度与资金留存。

## 全局导航栏

- 菜单项中，“投资组合”标签高亮为当前页面。

- 右侧功能区（模式切换、多语言、支持链信息、钱包状态）为全局组件，此处不赘述具体样式，仅说明钱包连接状态影响页面展示。

- 钱包模块已连接时显示地址缩略与下拉菜单；未连接时显示“连接钱包”按钮。

## 页面需求

### 3\.1 资产权益与操作中心（页面顶部）

#### 3\.1\.1 未登录状态

- 总净资产价值：展示 `--`

- 今日盈亏：**隐藏**（不展示今日盈亏徽章）

- **连接钱包入口**：仅顶部导航栏「连接钱包」；资产操作区**不展示**重复「连接钱包」按钮

- 快捷操作按钮组（划转 / 提现 / 充值 / 待处理）：**整组隐藏**

- VIP 权益卡片：等级、14 天交易量、Maker/Taker、升级进度均为 `--`；**「等级费率表」仍可点击**（见 3\.2\.2、3\.2\.3 未登录弹窗规则）

- 合约表现图：右侧展示「请先连接钱包」，不渲染图表

- 账户实时风险与累积统计：保证金比例、未实现盈亏、维持保证金、总交易量均为 `--`

#### 3\.1\.2 登录状态

- 总净资产价值

    - 定义：资金账户余额 \+ 交易账户保证金余额 \+ 所有未实现盈亏（若有），统一折算为 USDT 计价

    - 价值计算算法沿用现有系统，保留两位小数，直接截断（不四舍五入）

    - 实时更新：当用户充提、划转、交易产生盈亏时联动刷新

- 今日盈亏

    - 计算基准：今日 00:00 \(UTC\+8\) 时刻的净资产快照

    - 金额变动 = 当前净资产 − 今日零点净资产

    - 百分比 = （金额变动 ÷ 今日零点净资产） × 100%，若今日零点净资产为 0，则百分比显示 `--`

    - 展示格式：`+420.15 (+3.42%)`，正数绿色，负数红色，零值灰色

    - 每日零点重置零点快照值

- 快捷操作按钮

    - **待处理 (N)**：位于划转按钮左侧；N 为当前待处理事项数量（如充值/提现审核中等，以业务口径为准）。橙色实心按钮样式，数量以红色圆形角标展示。

    - 划转：打开资金划转弹窗（具体交互见“钱包登录\+充提\+划转”模块）

    - 提现：打开提现方式选择弹窗（同上模块）

    - 充值：打开充值方式选择弹窗（同上模块）

#### 3\.1\.3 分类账户余额栏

- 资金账户

    - 账户名称固定为“资金账户”，图标样式“F”

    - 展示总余额：该账户下所有币种折合 USDT 总和

    - 右侧“可用余额”数值等于总余额（资金账户无冻结资产）

    - 更新逻辑：随充值、提现、资金划转操作实时变化

- 交易账户

    - 账户名称固定为“交易账户”，图标样式“T”，整体采用蓝色调视觉区分

    - 展示总余额：交易账户中的保证金本金余额（不包含未实现盈亏），折合 USDT

    - 右侧“保证金余额”数值等于该账户余额

    - 更新逻辑：随资金划转（从资金账户转入/转出）、已实现盈亏结算、手续费扣除等操作实时变化

### 3\.2 VIP 权益卡片（左侧卡片）

#### 3\.2\.1 登录状态展示

- 当前 VIP 等级：如 `VIP 2`，带皇冠图标，等级名称金色高亮

- 近 14 天交易量

    - 定义：统计区间固定为从昨日（T\-1）00:00:00 起，向后回溯连续 14 个完整自然日的累计合约成交额，合计折合 USDT

    - 数值精确到小数点后两位，使用逗号分隔符，如 `$38,500,000.00`

    - 每日定时更新（建议 UTC\+8 00:30 前完成重算）

- 当前费率

    - Maker 费率：展示当前 VIP 等级对应的 Maker 手续费率，绿色高亮

    - Taker 费率：展示当前等级对应的 Taker 手续费率，绿色高亮

- 升级进度

    - 进度条计算公式：

    - text

    - 进度 = （近14天交易量 − 当前等级最低门槛）÷（下一等级最低门槛 − 当前等级最低门槛） × 100%

    - 若当前等级已为最高级，进度显示 100%，提示“已达最高等级”

    - 进度条下方显示文字：“距下一等級還差 $X”，X = 下一等级最低门槛 − 近14天交易量

    - 进度条颜色：已达成部分使用金色/蓝色，未达成部分为深灰色底色

- 等级费率表入口

    - 按钮“等级费率表”，点击弹出 VIP 费率详情弹窗（弹窗内容见 3\.2\.3）

#### 3\.2\.2 未登录状态

- 等级显示 `--`

- 近 14 天交易量显示 `--`

- Maker/Taker 费率显示 `-- / --`

- 进度条不展示，升级提示文字隐藏

- **等级费率表按钮可点击**：打开 VIP 费率详情弹窗（见 3\.2\.3 未登录弹窗变体）

#### 3\.2\.3 VIP 费率详情弹窗

- 弹窗标题：ForX 合约交易 VIP 費率表

- **已登录 · 个人交易量行**（表格上方）：
  - 左侧标签：`过去 14 天交易量`
  - 右侧数值：用户近 14 天合约累计成交额（USD），如 `$38,500,000.00`
  - **含义**：展示**当前用户个人**在过去 14 天内的实际成交量，与 VIP 卡片「近 14 天交易量」口径一致；**不是**下方表格「14天交易量門檻」列中的等级达标门槛。

- **未登录 · 个人交易量行**：**不展示**「过去 14 天交易量」行。

- **VIP 等级费率表**：
  - 表格展示各等级门槛与 Maker / Taker 费率
  - 列：VIP 等級、14天交易量門檻 (USD)、Maker 費率、Taker 費率
  - 等级范围：VIP 0 ~ VIP 4（具体门槛与费率见《费率》文档）
  - **已登录**：当前用户所在等级行高亮（黄底）
  - **未登录**：所有等级行均为普通样式，**不标记**用户档位

- **VIP 专属权益**（费率表下方，四宫格）：
  - VIP 资讯研报、VIP 礼物、VIP 会场、VIP 空投权益（第四项为展示型权益说明）
  - 详见《费率》文档 2.1 / 2.2

- **底部等級補充說明**：等级根据近 14 天交易量 T+1 日自动更新；交易量未达标会降级；新费率仅影响升级后新产生的交易。

- **其他入口**：合约交易页交易终端底部「手續費率」点击打开的弹窗，结构与本节一致（未登录规则同上）。

### 3\.3 合约账户表现仪表盘（右侧区域）

#### 3\.3\.1 布局结构

- 左右分栏：左侧为“实时风险 \+ 累积统计”，右侧为“周期绩效走势图”

- 左侧指标不受右侧时间周期切换影响，始终展示最新即时数据

- 右侧图表的时间周期按钮（7D/14D/30D）仅影响该图表显示的数据范围与粒度

#### 3\.3\.2 左侧：账户实时风险 \& 累积统计

实时风险区

- 保证金比例

    - 公式沿用现有系统（通常为：维持保证金 ÷（保证金余额 \+ 未实现盈亏））

    - 未持仓或保证金余额为 0 时显示 `0.00%`

    - 样式预警：

        - 安全（≤ 60%）：绿色

        - 预警（\> 60% 且 ≤ 90%）：黄色

        - 危险（\> 90%）：红色

    - 数值实时刷新

- 未实现盈亏

    - 定义：所有当前持仓按标记价格计算的浮动盈亏之和

    - 单位：USDT，保留两位小数

    - 正数为绿色，负数为红色

    - 更新频率：随标记价格变动实时变化

- 维持保证金

    - 定义：所有持仓所需的最低维持保证金总和，由各持仓的合约规格、杠杆倍数、持仓数量决定

    - 单位：USDT，保留两位小数

    - 空仓时显示 `0.00`

累积统计区

- 总交易量 \(Lifetime\)

    - 定义：账户自创建以来所有合约交易成交额的总和（买方成交额 \+ 卖方成交额），统一折算为 USDT

    - 永久累计，不受任何时间周期切换影响，即使平仓也不减少

    - 数值过大时使用 `M` / `B` 缩写（如 `138.5M`），同时保留精确数值用于 hover 提示

#### 3\.3\.3 右侧：周期绩效分析图

数据曲线

- 三色三条曲线叠加于同一图表：

    - 账户价值（蓝色实线）：所选周期内，各采样点的净资产快照值（资金账户 \+ 交易账户保证金 \+ 未实现盈亏）

    - 盈亏（绿色实线 \+ 半透明区域填充）：所选周期内，各采样点相对周期起始点的累计盈亏变动（已实现\+未实现）；起始点盈亏值为 0

    - 交易量（紫色虚线）：所选周期内，各采样间隔内的成交额（USD）平滑连线，使用虚线区分

- 采样频率：

    - 7D：每 2 小时一个数据点

    - 14D：每 4 小时一个数据点

    - 30D：每 8 小时一个数据点

- 图表底部横轴展示时间标签，末端标识“Today”或“最新”

- 鼠标悬停交互：

    - 显示垂直参考线，同时显示该采样点的日期、账户价值、盈亏金额、交易量

    - 数值浮窗不超出图表边界

动态汇总数值

- 图表上方展示当前周期对应的三个汇总指标：

    - 账户价值：周期内最新采样点的账户价值（USDT）

    - 盈亏：周期内累计盈亏金额，绿色/红色

    - 交易量：周期内总交易量，使用紫色

未登录状态

- 右侧整体显示静态文案：“请先连接钱包”，不渲染图表和指标

### 3\.4 底部数据流水明细标签页

底部提供「当前持仓」「当前委托」「历史委托」「历史成交」「历史持仓」「资金流水」「资金费用」「充提記錄」等标签（与《持仓管理 \+ 资金流水模块》对齐）。

**投资组合页嵌入规则（原型）**

| 标签 | 本页展示 |
|---|---|
| 当前持仓 / 当前委托 / 历史委托 / 历史成交 / 历史持仓 / 资金流水 / 资金费用 | **不内嵌完整表格**；展示引导文案，指向「合约交易页」下方持仓与流水管理（详见该模块文档） |
| 充提記錄 | **不展示**筛选与表格；展示占位说明「这部分原型请查看 Gary 输出的为准」（正式需求以 Gary 输出为准） |

完整字段、筛选、操作按钮等详见 《持仓管理 \+ 资金流水模块》需求文档。

## 弹窗模块

本页面涉及的充值、提现、资金划转弹窗，其完整交互流程、表单字段、校验规则及异常处理，请参见 《钱包登录\+充提\+划转》模块需求文档。此处仅说明页面触达入口：

- 充值弹窗：由“充值”按钮或钱包下拉菜单中的“充值”入口唤起

- 提现弹窗：由“提现”按钮唤起

- 资金划转弹窗：由“划转”按钮唤起

以上弹窗均以模态形式居中展示，背景半透明遮罩，关闭后返回投资组合页并刷新相关余额数据。

## 补充说明

- 所有涉及货币金额的显示，默认精确到小数点后两位，大数可适当缩写，但需提供精确值悬停提示。

- 时间相关统计一律以 UTC\+8 时区的自然日 00:00:00 为起止点。

- 页面数据刷新采用定时轮询 \+ 关键操作后主动拉取结合，确保前端展示与服务端状态一致。

- VIP 等级更新延迟说明：每日快照数据可能存在短暂延迟，页面需显示数据更新时间戳（可选，或仅提示“每日更新”）。
