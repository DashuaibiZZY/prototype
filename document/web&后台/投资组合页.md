# 投资组合页（Web）

- **原型地址**：[投资组合.html](https://dashuaibizzy.github.io/prototype/perp_dex/%E6%8A%95%E8%B5%84%E7%BB%84%E5%90%88.html)（页面顶部黄色虚线栏为原型状态切换器，非线上元素）
- **整体结构**：顶部三级主 Tab（`资产总览` / `资金账户` / `合约账户`）+ 右侧全局操作按钮组（`待处理(N)` / `划转` / `提现` / `充值`）；下方按所选 Tab 渲染对应视图。

---

## 一、全局规则

### 1.1 顶部操作按钮（三视图共用）

| 按钮 | 说明 |
|---|---|
| **待处理(N)** | 橙色按钮 + 红色圆形角标，展示待处理事项数（如充提审核中）；未登录隐藏 |
| **划转 / 提现 / 充值** | 分别唤起资金划转、提现、充值弹窗（完整流程见《登录、划转与充提》文档）；未登录整组隐藏 |

### 1.2 估值单位切换（三视图全局联动）

- **触发入口**：以下 3 处金额后方均放置一个**向下无直线箭头**，点击展开下拉菜单：
  1. `资产总览` → `总资产价值`
  2. `资金账户` → `账户权益`
  3. `合约账户` → `账户权益`
- **下拉菜单内容**：
  - 标题：`估值单位`
  - 选项：`USD 美元`（默认，前缀 `$`）、`USD Coin`（后缀 `USDC`）、`JPY 日元`（前缀 `¥`）
  - 交互：当前选中项右侧打勾；点击外部区域或按 `Esc` 收起。
- **联动范围**：
  - 三处下拉共用全局状态，任意一处切换后，另外两处同步更新。
  - **跟随换算字段**：三视图所有估值类金额（总资产价值、今日盈亏、资产组合余额、账户权益、今日已实现盈亏、可用保证金、未实现盈亏、累计交易量）、右侧折线图数值、各视图底部 `资产列表` 的 `资产价值` 列、顶部钱包下拉菜单总资产。
  - **不跟随换算字段（例外）**：`体验金余额`、`待使用`、`使用中` 固定以 `USDC` 展示；VIP 14 天交易量门槛与进度统计口径保持 `USD`。

### 1.3 未登录状态与通用口径

| 区域 | 未登录展示规则 |
|---|---|
| 顶部导航 / 操作按钮 | 导航栏显示「连接钱包」；主 Tab 右侧 `待处理 / 划转 / 提现 / 充值` 整组隐藏 |
| 资产与账户指标 | 所有金额与百分比展示 `--` |
| 右侧折线图 | 覆盖蒙层文案「请先连接钱包」，不渲染曲线 |
| VIP 信息横幅 | 等级 `VIP --`，14 天交易量 / Maker / Taker 均为 `--`，隐藏升级进度；「等级费率表」仍可点击 |
| 资产列表 / 资金账单 | 展示空态引导文案「请先连接钱包查看资产列表 / 资金账单」 |

- **通用口径**：金额默认保留两位小数直接截断（不四舍五入）；自然日统计均以 `UTC+8 00:00:00` 为起止基准；支持定时轮询 + 充提/划转/交易后主动刷新。

## 二、三大主视图需求

### 2.1 资产总览（默认 Tab）

1. **顶部概览卡片（左右分栏）**
   - **左侧**：
     - `总资产价值`（含估值单位下拉）：资金账户余额 + 合约账户权益（含未实现盈亏）折算合计。
     - `今日盈亏`：展示 `金额 + 涨跌幅`（以当日 `UTC+8 00:00` 净资产快照为基准；基准为 0 时涨跌幅显示 `--`；正绿、负红、零灰）。
     - `资产组合`：展示 `资金账户`、`合约账户` 两行余额，点击整行直接跳转至对应主 Tab。
   - **右侧**：`账户价值` 单折线图，支持 `7D / 14D / 30D` 周期切换，顶部展示所选周期最新账户价值。
2. **中部**：`VIP 信息横幅`（详见第三节）。
3. **底部**：`资产列表`（展示资产项总数；列：`名称` / `数量` / `资产价值`；当前覆盖 `USDC`、`USD1`）。

### 2.2 资金账户

1. **顶部概览卡片（左右分栏）**
   - **左侧**：`账户权益`（含估值单位下拉），标题与右侧 `账户价值` 水平对齐，展示资金账户全部资产折算总额。
   - **右侧**：`账户价值` 单折线图（`7D / 14D / 30D`）。
2. **中部**：不展示 VIP 信息横幅。
3. **底部 3 个子 Tab**：
   - `资产列表`：列 `名称` / `数量` / `资产价值`。
   - `充提记录`：交互与字段以 Gary 输出原型为准。
   - `资金账单`：
     - 筛选栏：周期快捷切换（`近1日` / `近7日` / `近30日` / `近90日`）+ 日期范围 + `账单主类型` 下拉（全部 / 充值 / 提币 / 转入 / 转出 / 空投奖励 / 返佣）+ `查询` / `重置`。
     - 列表列：`时间` / `币种` / `账单主类型` / `数量`（正绿负红）/ `账户余额`。

### 2.3 合约账户

1. **顶部概览卡片（左右分栏）**
   - **左侧**：
     - `账户权益`（含估值单位下拉），标题与右侧折线图 Tab 栏水平对齐。
     - `今日已实现盈亏`：位于 `账户权益` 下方小字展示（`UTC+8 00:00` 基准，正绿、负红、零灰，跟随估值单位换算）。
     - 账户指标：`可用保证金`、`未实现盈亏`、`累计交易量`（均跟随估值单位换算）。
     - `体验金余额`：含缩进子项 `待使用`、`使用中`，**固定 `USDC` 单位，不随估值单位切换**。
   - **右侧**：3 指标单曲线切换折线图，顶部支持切换 `账户价值`（蓝）/ `盈亏`（绿）/ `交易量`（紫）及周期 `7D / 14D / 30D`，实时展示当前指标数值（跟随估值单位换算）。
2. **中部**：`VIP 信息横幅`（与 `资产总览` 复用同一组件）。
3. **底部 8 个子 Tab**（不含 `资金账单`）：
   - `资产列表`：列 `名称` / `数量` / `资产价值`。
   - `当前持仓(N)` / `当前委托(N)` / `历史委托` / `交易账单` / `体验金账单` / `历史持仓` / `资金费用`：复用《持仓管理 & 资金流水模块》规格。

## 三、VIP 信息横幅 & 等级费率表弹窗

### 3.1 VIP 信息横幅（展示于 `资产总览` 与 `合约账户` 中部）

| 状态 | 左侧标题与副信息 | 过去 14 天交易量 & 费率 | 升级进度区 | 等级费率表按钮 |
|---|---|---|---|---|
| **自然 VIP（默认）** | `VIP X` + 权益简述 | 展示近 14 天交易量（T-1 回溯 14 个自然日，USD）+ 当前 Maker / Taker 费率 | 展示升级至下一级进度条与差额（最高级满进度） | 可点击 |
| **运营自定义费率** | `专享费率生效中`；非永久时下方展示 `费率有效期至 YYYY-MM-DD 24:00 (UTC+8)`，永久不展示 | 展示近 14 天交易量 + 当前实际生效 Maker / Taker 费率 | **隐藏** | 可点击 |
| **未登录** | `VIP --` | 交易量 / Maker / Taker 均展示 `--` | **隐藏** | 可点击 |

### 3.2 VIP 等级费率表弹窗（点击「等级费率表」打开）

弹窗标题：`ForX 合约交易 VIP 费率表`，自上而下包含 4 个模块（与合约交易页费率弹窗一致）：

1. **过去 14 天交易量**：展示当前用户近 14 天个人累计合约成交额（USD）；**未登录态隐藏该行**。
2. **VIP 阶梯费率**：列 `VIP 等级` / `14天交易量门槛 (USD)` / `Maker 费率` / `Taker 费率`（VIP 0 ~ VIP 5，读取后台已发布配置）；仅自然 VIP 登录态高亮当前等级行，未登录与专享费率用户均不高亮。
3. **特定交易对费率**：列 `交易对` / `Maker 费率` / `Taker 费率`（如 `BTCUSDC` / `ETHUSDC` / `BCHUSDC` / `LTCUSDC`），支持分页（每页 5 条，底部显示总条数与页码切换）。
4. **VIP 专属权益 & 等级补充说明**：四宫格权益展示（VIP 资讯研报、VIP 礼物、VIP 会场、VIP 空投权益）+ T+1 升降级与新交易生效说明。
