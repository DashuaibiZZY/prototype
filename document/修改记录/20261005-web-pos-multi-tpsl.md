# Web 当前持仓 · 多条止盈止损展示

- **当前持仓 · 止盈/止损列**：上下两行（止盈 / 止损）；多条委托时价格右侧 `(N)`；开多/开空汇总规则见《持仓管理 & 资金流水 模块》§3.1.3。
- **止盈止損設置弹窗**：已设置态（委托列表 + 全部撤单 / 继续添加）；未设置态（无止盈止损单 + 立即添加）。
- **表单子弹窗**：继续添加 / 立即添加 / 修改 → 同弹窗内表单视图（止盈止损触发、委托价、数量滑杆、確認設置）；顶部开仓均价/标记价/持仓数量始终展示；**返回** 回到列表/空态。
- **撤单 / 修改**：单条撤单后列表即时移除；修改进入表单时预填该条触发价、价格类型、市价/限价与数量。
