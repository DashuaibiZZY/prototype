# 合约详情 · 交易规则字段对齐交易对配置

**日期：** 2026-10-01

## 原型

- Web `perp_dex/合约交易.html` 详情 Tab「交易規則」网格
- App `perp_dex/app/交易对信息.html`

## 字段（8 项）

市场、最大杠杆、价格精度、最小步进、单笔最小/最大成交价值、最大持仓数量、最大挂单数。

## 文档

- 《合约交易页》§3.5.2
- 《APP 端合约交易页》§7.2.3

**最大杠杆**：取交易对配置 **维护保证金率阶梯** `maintenance_margin_rate` 中各档 `max_level` 的**最大值**。其余字段对应 `price_precision` 与 `limit_config.*`（见 PRD 表格）。
