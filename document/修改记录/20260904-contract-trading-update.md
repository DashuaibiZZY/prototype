> 覆盖 App / Web 合约交易页、持仓+流水模块、App 交易流水页。

## 1. 子 Tab 命名：基础单 → 限价｜市价

|端|位置|变更|
|---|---|---|
|App|合约交易页 · 当前委托|二级 Tab `基础单` → **限价｜市价**|
|App|交易流水页 · 当前/历史委托|同上|
|Web|持仓模块 · 当前/历史委托|子标签 `基础单` → **限价｜市价**|
|App|全部取消弹窗|选项文案同步为「限价｜市价」|

**需求逻辑：**

- 「限价｜市价」指常规限价单、市价单及其生效类型变体（GTC / Post Only / FOK / IOC），与「止盈止损单」条件委托区分。
- 卡片/表格**不在标签行重复展示「限价」「市价」字样**（订单类型由下单入口决定）；历史委托标签行仍保留委托类型字段（限价/市价/强平）。

## 2. 订单生效类型（TIF）

### 2.1 Web 交易终端

- 限价模式下展示「生效时间」下拉；**GTC、Post Only** 在上，**FOK、IOC** 在下。
- 终端按钮选中后**仅展示英文**：`GTC` / `Post Only` / `FOK` / `IOC`。
- 市价单固定 IOC，不展示选择器；止盈止损单固定 GTC，不展示选择器。

### 2.2 App 交易终端

- **无独立「生效时间」选择器**；通过订单类型 Bottom Sheet 隐式映射：

|订单类型选项|等价生效类型|终端展示|
|---|---|---|
|限价|GTC|限价|
|Post Only|Post Only|只挂单|
|限价（FOK）|FOK|限价（FOK）|
|限价（IOC）|IOC|限价（IOC）|
|市价|IOC|市价|

- 全局文案：**Post Only**（非 Post only）；列表标签用 **只挂单(Post Only)**。

### 2.3 委托列表展示

**Web（限价｜市价子标签）**

- 独立列「生效类型」，取值：`GTC` / `Post Only` / `FOK` / `IOC`（与后端一致）。

**App（卡片头部）**

- 当前委托与历史委托 · 限价｜市价**共用**标签规则：Post Only / FOK / IOC 时展示浅蓝框标签，取值 `只挂单(Post Only)`、`FOK`、`IOC`；GTC 不展示。
- 强平委托：红色 `強平委託` 标签，与 TIF 标签分场景展示。

## 3. 委托卡片字段与标签规范

### 3.1 交易方向（统一）

- 全端列表统一四字：**开多 / 开空 / 平多 / 平空**（非「买入开多」等六字）。
- 色块：开多/平空绿；开空/平多红。

### 3.2 委托时间

- 格式：`MM/DD HH:mm:ss`（如 `06/11 18:59:34`）。
- 位置：标签行**最右侧**右对齐（App 卡片；Web 为独立列）。

### 3.3 移除「永续」标识

- 当前/历史委托卡片、列表**不再展示**「永续」字样。

### 3.4 盈亏 (ROE%)（Web）

- 两行：第一行金额 `+166.05 USDC`，第二行 `(+25.40%)`；虚线可悬停已实现盈亏拆解。

## 4. 当前持仓：杠杆与逐仓保证金调整

|能力|全仓|逐仓|入口|
|---|---|---|---|
|调整杠杆|✓|✓|杠杆色块**内嵌**编辑图标，整框可点|
|调整保证金|—|✓|保证金数值右侧蓝色「+」|

**调整杠杆弹窗字段：** 槓桿（当前 Nx、步进器/滑块）、調整後最大可開、所需保证金、预估强平价；逐仓且**调低**杠杆时提示从余额转出 USDC 至逐仓保证金。

**调整保证金弹窗（仅逐仓）：** 增加/减少 Tab、数量(USDC)+滑块、最多可增加/减少、调整后强平价、调整后杠杆倍数。

- App：Bottom Sheet；Web：居中 Modal（样式各端独立）。

## 5. 历史委托详情页（App）

- 独立页「订单详情」；点击历史委托**整张卡片**进入。
- 限价｜市价详情含：生效类型（GTC / 只挂单(Post Only) / FOK / IOC）、成交明细等。
- 强平/过期/取消等状态头部展示独立文案与图标。
