# App 端交易流水页

**原型**：[https://dashuaibizzy.github.io/prototype/perp_dex/app/交易流水頁面.html](https://dashuaibizzy.github.io/prototype/perp_dex/app/交易流水頁面.html)

**子页面原型（历史委托详情）**：[https://dashuaibizzy.github.io/prototype/perp_dex/app/历史委托详情页.html](https://dashuaibizzy.github.io/prototype/perp_dex/app/历史委托详情页.html)

## 模块概述

### 1\.1 页面定位

页面截图：[**App · 交易流水页整体**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/交易流水-app/app-flow-page.png)

交易流水页是 App 端集中展示用户合约交易相关数据的核心页面。与 Web 端相比，App 端字段更精简，交互适配移动端触控操作。

- 原型链接：见文档顶部。

### 1\.2 与 Web 端差异

- 页面名称：App 端称为“交易流水页”，Web 端为“持仓管理 \& 资金流水模块”。

- Tab 差异：App 端无「当前持仓」和「充提记录」两个标签。

- 字段精简：App 端每个标签展示字段更少，采用卡片式布局，适配小屏。

- 历史委托详情：App 端支持点击历史委托卡片进入独立详情页。

- 交互方式：筛选使用底部弹窗（Bottom Sheet），而非 Web 端的浮层/下拉。

## 页面布局

### 2\.1 整体结构

┌──────────────────────────┐

│       顶部导航栏         │  ← 返回按钮 \+ 页面标题 "合约流水"

├──────────────────────────┤

│     一级标签栏 \(横向\)    │  ← 当前委托\(3\) \| 历史委托 \| 持仓历史 \| 历史成交 \| 资金流水 \| 资金费率

├──────────────────────────┤

│  二级标签栏 \(条件显示\)   │  ← 基础单\(1\) \| 止盈止损单\(2\)  （仅当前委托/历史委托显示）

├──────────────────────────┤

│  筛选栏 \+ 全部取消按钮   │  ← 各标签动态筛选按钮 \+ 全部取消按钮\(仅当前委托显示\)

├──────────────────────────┤

│       数据列表           │  ← 卡片式列表，支持纵向滚动

└──────────────────────────┘

#### 6\.5\.2 已实现盈亏拆解弹层（持仓历史）

页面截图：[**App · 已实现盈亏拆解弹层**](https://raw.githubusercontent.com/DashuaibiZZY/prototype/doc-assets/document/assets/交易流水-app/app-flow-sheet-realized-pnl.png)

**触发方式：** 点击卡片中「已實現盈虧 (USDT)」**标签文案**（虚线下划线处）；下方数值仅作展示，不可点击。

**弹层形式：** 底部 Bottom Sheet；标题「已實現盈虧明細」；点击遮罩或「關閉」关闭。

**弹层结构：**

|区域|字段|说明|
|---|---|---|
|标题区|已实现盈亏|小标题 + 合计值（加粗）|
|分隔线|—|区分标题与明细|
|明细区|平仓盈亏|该笔历史持仓全部平仓产生的盈亏合计|
|明细区|资金费用|持仓期间资金费用累计|
|明细区|交易手续费|相关全部成交手续费累计|

**数值定义与计算口径：**

- **已实现盈亏（合计）** = 平仓盈亏 + 资金费用 + 交易手续费。

- **统计范围**：该笔历史持仓从首次开仓至仓位完全关闭的整个生命周期：

    - **平仓盈亏**：全部平仓成交产生的已实现盈亏。

    - **资金费用**：持仓期间各结算周期资金费用累计。

    - **交易手续费**：须包含最初开仓手续费、中间过程每一次开平仓手续费，以及最后一笔完全平仓手续费。

- 卡片展示的已实现盈亏数值须与弹层标题区合计值一致；明细三项之和等于合计值。

**展示规则：** USDT、两位小数、正负色；与 App 合约交易页当前持仓拆解弹层（《APP 端合约交易页》4\.2\.2\.1）结构一致。

#### 6\.5\.3 状态与颜色

状态枚举：

- 完全平仓

- 部分平仓（仓位已关闭）

方向色块：

- 买入/做多：绿色方块 `買`

- 卖出/做空：红色方块 `賣`

颜色规则：

- 已实现盈亏正数：绿色

- 已实现盈亏负数：红色

- 投资回报率同色。

分享功能：

- 右侧客服/帮助图标（按产品配置）。

### 7\.5 基础单详情字段

#### 7\.5\.1 通用信息区（所有状态展示）

|字段|说明|
|---|---|
|訂單號|平台订单号；旁附复制图标|
|類型|订单类型 / 方向，如「市價 / 平多」|
|數量 / 成交數量|格式「委托量 / 成交量」（USDT）|
|均價 / 價格|格式「成交均价 / 委托价」；未成交部分为 `--`|
|只減倉|是 / 否|

#### 7\.5\.2 附加信息区（全部成交 / 部分成交）

|字段|说明|
|---|---|
|手續費|该订单累计手续费（USDT），负值展示|
|已實現盈虧|平仓类订单的已实现盈亏；盈利绿色、亏损红色|
|創建時間|订单创建时间|
|更新時間|订单最后更新时间|

#### 7\.5\.3 附加信息区（已取消 / 已过期）

|字段|说明|
|---|---|
|手續費|`--`（无成交）|
|撤銷時間 / 過期時間|用户撤销或系统过期时间|
|成交明细区|不展示；底部显示「已經全部加載完畢」|

#### 7\.5\.4 附加信息区（强平委托成交）

|字段|说明|
|---|---|
|強平價格|强平触发价格，红色强调|
|已實現盈虧|强平产生的已实现盈亏|

#### 7\.5\.5 成交明细区（全部成交 / 部分成交 / 强平成交）

区块标题「成交明細」，按每笔成交展示：

|字段|说明|
|---|---|
|时间|该笔成交时间|
|數量|成交数量（USDT）|
|價格|成交价格|
|盈虧|该笔成交盈亏|
|手續費|该笔成交手续费|
|角色|吃單 / 掛單|

已取消、已过期订单不展示此区域。

### 7\.6 止盈止损单详情字段

|字段|说明|
|---|---|

## 筛选弹窗交互

### 8\.1 弹窗形式

所有筛选弹窗均使用底部弹窗（Bottom Sheet），从屏幕底部滑入。

### 8\.2 通用结构

- 顶部拖拽条（灰色短横条）。

- 弹窗标题（居中或左对齐）。

- 选项区域（网格按钮或列表）。

- 底部操作按钮（重置 \+ 确认）。

### 8\.3 日期筛选弹窗

内容：

- 快捷时间选项：最近1天、最近1周、最近1月、最近3月（网格排列，高亮选中项）。

- 自定义区间：起始日期 \- 结束日期（可点击进入日期滚轮选择）。

- 日期滚轮：年、月、日三列滚轮选择器（模拟 iOS 样式）。

- 提示文字：`*仅支持查询近3个月记录`。

交互：

- 点击快捷时间选项，直接选中并关闭弹窗。

- 点击自定义区间，弹出日期滚轮，滑动选择日期后确认。

- 点击重置恢复默认，点击确认应用并关闭。

### 8\.4 合约筛选弹窗

内容：

- 搜索框（可输入币对名称搜索）。

- 当前合约标签（蓝色背景高亮显示当前选中合约）。

- 合约列表（全部 \+ 各交易对，当前选中项右侧有蓝色对勾 ✓）。

交互：

- 点击列表项选中合约，弹窗关闭并应用筛选。

### 8\.5 订单类型/方向/仓位模式/状态等筛选弹窗

内容：

- 标题（如“订单类型”）。

- 选项网格（2列或1列按钮排列，高亮选中项）。

- 状态类筛选支持多选（右上角有勾选角标）。

交互：

- 单选类：点击选项直接选中并关闭弹窗。

- 多选类：点击选项切换勾选状态，点击外部关闭弹窗或自动保存选择。

### 8\.6 资金流水类型筛选弹窗

内容：

- 垂直列表排列（每行一个类型）。

- 当前选中项右侧有蓝色对勾 ✓。

交互：

- 点击类型选项，切换选中状态（单选），弹窗关闭。

## 全局交互

### 9\.1 分享海报弹窗

- 触发：持仓历史卡片中的分享图标。

- 内容：品牌标识、合约、方向、收益率、开仓/平仓价格、时间、平台网址。

- 操作：取消按钮关闭，分享海报按钮（App 端调用系统分享）。

### 9\.2 全部取消弹窗

**触发：**当前委托页的“全部取消”按钮。

**流程：**

1. 点击按钮 → 弹出底部弹窗（订单类型筛选），显示垂直选项：全部、限价、止盈止损。

2. 点击任一类型 → 弹窗内容直接切换为确认取消弹窗（无需二次弹出），确认弹窗内容包含：警示图标、“取消全部订单”标题、“确认撤销所有委托单么？”提示、取消/确认双按钮。

3. 点击“确认” → 系统仅撤销用户在第一步所选类型的所有委托：

    - 若选择全部：撤销当前合约下所有活跃订单（基础单 \+ 止盈止损单）；

    - 若选择限价：仅撤销所有基础单（限价单、市价单等）；

    - 若选择止盈止损：仅撤销所有止盈止损单。

4. 撤销完成后关闭弹窗，并显示 Toast 提示（如“已撤销全部订单”、“已撤销所有限价单”、“已撤销所有止盈止损单”）。并刷新页面数据。

5. 点击“取消”关闭弹窗，不执行任何操作。

### 9\.3 订单号复制

- 历史成交卡片、历史委托详情页中的订单号旁有复制图标。

- 点击后复制订单号到剪贴板，Toast 提示“已复制”。

### 9\.4 下拉刷新

- 列表页面支持下拉刷新，重新加载当前标签数据。

### 9\.5 空数据

- 列表无数据时，显示“暂无数据”空状态。
