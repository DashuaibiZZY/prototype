# 交易对标签配置及填充逻辑

本文档说明永续合约**交易对标签 Tab**、**首页首屏行业分类展示**及「热门」「新币上线」等标签的**填充规则**。适用于 APP 首页、APP/Web 行情页、APP/Web 合约交易页「选择合约/交易对」弹层。

**关联原型**

- [APP 合约交易页](https://dashuaibizzy.github.io/prototype/perp_dex/app/合约交易.html)
- [Web 合约交易页](https://dashuaibizzy.github.io/prototype/perp_dex/合约交易.html)

## 1. 首页首屏 · 行业分类标签

与行情/合约页的**标签 Tab 栏相互独立**，仅用于首页顶部 2×2 行情卡片展示。

| 字段 | 说明 |
|---|---|
| 行业分类标签 | 如「加密货币」「股票」「大宗商品」。灰色小字展示于卡片名称下方 |
| 首页顶部显示排序编号 | 整数，默认 `0`；`≥1` 按升序取前 **4** 个展示于首屏卡片 |

**规则**

- 取「首页顶部显示排序编号 ≥ 1」的交易对，按编号升序，最多 4 个。
- 卡片展示：名称、**行业分类标签**、迷你 K 线、最新价、24h 涨跌幅。
- 该字段**不参与**行情页/合约页标签 Tab 的筛选逻辑。

## 2. 标签 Tab 栏（单层结构）

行情页、合约页「选择合约/交易对」弹层采用**单层**可横向滚动的标签 Tab，**无二级面板**。

**Tab 组成（按 `priority` 升序排列）**

| 顺序 | 标签 | 类型 | 可删除 | priority |
|---|---|---|---|---|
| 1 | **全部** | 系统默认 | 否 | **固定最高**（默认 `0`，不可被其他标签超越） |
| 2 | **新币上线** | 系统默认 | 否 | 可调（默认 `1`） |
| 3 | **热门** | 系统默认 | 否 | 可调（默认 `2`） |
| 4+ | 自定义标签 | 后台配置 | 是 | 后台配置（如主流币、AI、TradeFi） |

**priority 规则**

- 数值越小越靠前；**「全部」始终为最高优先级**（默认 `priority = 0`）。
- 「新币上线」「热门」可调整 priority，但**不可删除、不可下架**。
- 自定义标签可增删；下架后前端隐藏；新增需配置 priority。

**「全部」Tab**

- 展示所有已上线交易对，不做标签过滤。

**自定义标签 Tab**

- 展示后台为该标签挂载的交易对；按产品规则排序（默认与「全部」一致或按后台配置）。

## 3. 「热门」标签 · 排序与填充

### 3.1 属性

- 「热门」Tab **入口前端写死**，后台不可删除。
- 列表内容**优先**由后台 **rank** 配置决定；行情页不足 20 条时可按成交量补齐。

### 3.2 后台 rank 配置

管理员为「热门」配置交易对及 **rank**（从 1 开始的连续正整数，不重复，越小越靠前）。

| 页面/场景 | 截取数量 |
|---|---|
| APP 首页 · 热门 Tab | 前 **5** 个 |
| APP 首页 · 无自选时的推荐收藏 | 前 **6** 个 |
| APP 行情页 / 合约页 · 热门 Tab | 前 **20** 个（可补齐） |

- 配置超过 N：仅展示前 N 个。
- 首页场景（5 / 6）：**不自动补齐**，有几个展示几个。

### 3.3 展示逻辑

1. 获取后台 rank 列表，按 rank **升序**。
2. 各页面截取前 N 个。
3. 前端不参与热度算法；顺序以后台 rank 为准（补齐段除外）。

### 3.4 行情页 · 不足 20 条时补齐

**触发**：rank 配置条数 **< 20**。

1. `缺口 = 20 - rank 条数`
2. 从全站已上线交易对中，按 **24h 成交额（USDT）降序** 取候选
3. **排除**已在 rank 列表中的交易对
4. 补齐段排在 rank 段**之后**；补齐段内部按成交量降序
5. 候选不足则展示实际长度，不强求 20

## 4. 「新币上线」标签 · 填充逻辑

### 4.1 属性

- 「新币上线」Tab **入口前端写死**，后台不可删除；`priority` 可调。
- **列表不由后台逐条 rank 配置**，按**开盘/上线时间**自动填充。

### 4.2 填充规则

1. 取所有**已开放交易**（非待开盘）的永续合约交易对。
2. 筛选条件：正式开盘时间落在**过去 30 天以内**（含第 30 天，以服务端统一时区日界为准）。
3. 排序：按开盘时间**倒序**——**最新上线的排在最前**。
4. 待开盘（倒计时）交易对**不进入**本列表（仍可在「全部」或搜索中找到）。

### 4.3 与后台的关系

- 运营**无需**为新币 Tab 手动维护交易对列表。
- 若某交易对超过 30 天，自动从「新币上线」Tab 消失。
- 自定义标签仍可手动挂载「新币」类营销标签，与系统「新币上线」Tab 无关。

## 5. 首页行情 Tab 区（独立逻辑）

首页中部行情 Tab（收藏 / 热门 / 新币上线 / 涨幅榜 / 跌幅榜）与行情页标签 Tab **相互独立**：

| 首页 Tab | 数据说明 | 查看更多跳转 |
|---|---|---|
| 收藏 | 用户自选，前 5 条 | `行情.html?tab=all` |
| 热门 | rank 前 5 | `行情.html?tab=hot` |
| 新币上线 | 30 天内新币，前 5 | `行情.html?tab=new` |
| 涨幅榜 | 24h 涨幅 Top 5 | `行情.html?view=gainers` |
| 跌幅榜 | 24h 跌幅 Top 5 | `行情.html?view=losers` |
